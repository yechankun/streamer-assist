Streamer Assist is a Windows app for broadcasters. After the user authorizes their YouTube channel, it identifies the channel and active broadcast, reads live chat and supported Super Chat messages for local archives, raffles and vote totals, and creates/closes YouTube native live polls at the user's request. Poll creation uses liveChatMessages.insert with pollEvent; closing uses liveChatMessages.transition with status=closed. These write operations accept youtube.force-ssl or youtube; youtube.readonly cannot perform them. The app does not upload, edit or delete videos, ratings, comments or captions. Tokens and original archives are encrypted on the user's PC. Optional external AI analysis runs only on user request for a selected record scope, as disclosed in the privacy policy. Users can disconnect the account, revoke Google access and delete local records.
