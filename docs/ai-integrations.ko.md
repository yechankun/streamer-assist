# AI 연결과 채팅 분석

[English](ai-integrations.md)

설정 → **AI 연결 → +**에서 사용할 AI를 선택합니다. 추가한 AI만 목록과 설정 카드에 표시되며, 필요한 연결 모듈을 자동으로 내려받습니다. 준비가 끝나면 **CLI/API** 방식을 선택합니다. 방송 타임라인 → **AI 분석**에서는 방송·플랫폼·날짜·경과 시간 범위와 요청을 선택합니다. 하이라이트, 질문, 반응, 후원 요약 예시를 사용하거나 원하는 질문을 직접 입력할 수 있습니다. 외부 AI 분석은 실행 버튼을 눌렀을 때만 시작합니다.

## 지원 방식

| 서비스 | CLI | API |
| --- | --- | --- |
| OpenAI | [Codex](https://developers.openai.com/codex/noninteractive), 기존 ChatGPT/CLI 로그인 | OpenAI Responses API |
| Anthropic | [Claude Code](https://code.claude.com/docs/en/headless), 기존 CLI 로그인 | Claude Messages API |
| xAI | [Grok Build](https://docs.x.ai/build/cli/headless-scripting) | xAI Chat Completions |
| Google | [Antigravity CLI](https://antigravity.google/docs/cli/headless/) | 별도 서비스인 Gemini API |
| DeepSeek | [공식 안내의 Codex 연결](https://api-docs.deepseek.com/quick_start/agent_integrations/codex/) · DeepSeek API 키 사용 | DeepSeek Chat Completions |
| Moonshot | [Kimi Code CLI](https://www.kimi.com/code/docs/en/kimi-code-cli/reference/kimi-command.html) | Kimi/Moonshot Chat Completions |

CLI 구독과 API 키의 이용 권한·요금은 각각 다릅니다. 모델은 직접 입력하지 않습니다. CLI의 모델 조회 명령·제어 프로토콜 또는 API의 모델 목록에서 실제 조회한 항목만 선택합니다. 모델과 추론 강도는 설정 → AI 연결에서만 저장하며 분석 화면은 저장된 설정을 사용합니다. 지원되는 모델의 추론 옵션만 선택할 수 있으며, 서비스 기본값을 고르면 옵션을 강제로 바꾸지 않습니다. CLI나 모델이 필수 실행 옵션을 지원하지 않으면 실패 이유를 표시합니다.

## 구성요소 관리

**설치 찾기**로 PC의 기존 CLI를 찾거나 **다운로드·설치**로 앱 프로필의 ai/components/에 설치합니다. 앱에서 설치한 구성요소는 업데이트·이전 버전 복원·제거할 수 있습니다. PC에 따로 설치한 CLI는 앱에서 삭제하지 않습니다. 로그인 버튼은 해당 CLI의 로그인 창을 엽니다.

CLI 실행 파일은 설치 프로그램과 ASAR에 포함하지 않습니다. 공식 릴리즈 메타데이터에서 버전을 확인하고 SHA-256/SHA-512로 다운로드를 검증합니다. 설치 중 취소·오류가 나면 기존 버전을 유지합니다. API 연결은 공통 HTTP 실행기를 사용하므로 서비스별 SDK를 추가로 설치하지 않습니다. 사용하지 않는 연결을 해제하거나 직접 추가한 연결을 제거할 수 있습니다.

연결 목록의 **+** 버튼에서 JSON 연결 파일을 가져올 수 있습니다. 새 호환 API는 설치된 연결 모듈의 프로토콜 구현을 사용하며, HTTPS와 로컬 localhost 주소를 지원합니다. 이 파일은 주소와 호환성 메타데이터만 포함합니다. 실행 가능한 연결 모듈은 아래의 고정된 GitHub 저장소에서 검증 후 설치합니다.

```json
{
  "schemaVersion": 1,
  "id": "custom-local-model",
  "name": "로컬 AI",
  "protocol": "chat",
  "baseUrl": "http://127.0.0.1:1234/v1",
  "models": []
}
```

모델별 추론 옵션 변경은 type: model-capabilities 파일로 갱신할 수 있습니다. 이 메타데이터만으로 선택 가능한 모델을 추가하지 않으며, 모델 목록은 연결된 API에서 조회합니다. CLI 실행 플래그·출력 프로토콜 변경은 해당 연결 모듈 업데이트로 대응합니다. 공통 호스트 ABI가 바뀌는 경우 앱 업데이트가 필요합니다.

## 전송 범위와 결과

전체 선택 범위를 읽어 건수를 집계하고, 입력 한도를 넘으면 기간 전체에서 결정적 샘플을 고릅니다. 화면에 **전송하는 기록 수 / 전체 기록 수**, 용량, 대략적인 토큰 수, 샘플링 여부를 표시합니다. 모델의 실제 토큰 수는 응답 후 제공되는 사용량으로 확인합니다. 샘플 분석을 전체 원문 분석으로 표시하지 않습니다.

기본값은 공개 닉네임을 가명으로 바꾸고 공개 계정 ID를 제외합니다. 같은 화자를 연결하는 분석용 ID, 플랫폼, 시점, 본문은 유지합니다. 본문에 적힌 개인정보는 자동 삭제하지 않습니다. 공개 식별 정보 포함은 직접 선택합니다. 시청자 채팅을 실행 지시로 취급하지 않으며 AI 출력도 텍스트로만 표시합니다.

API 키와 결과는 Windows 보안 저장소로 암호화합니다. 저장된 키를 화면으로 다시 반환하지 않습니다. 요청 중지, 저장된 결과 선택·삭제를 지원합니다. 결과는 제한된 수로 보관하며 원본 채팅과 별도로 관리합니다. 외부 서비스나 CLI 자체 로그의 보관 정책은 해당 서비스가 관리합니다.

## 사용량·한도·요금

CLI는 공식 출력이나 공식 읽기 전용 프로토콜에서 제공한 한도를 표시합니다. Codex는 세션·주간 창과 초기화 시각을 조회하며, 다른 CLI는 제공되는 한도 이벤트를 표시합니다. 서비스가 외부 조회를 제공하지 않으면 조회 불가 이유를 표시합니다. CLI 한도를 추측하거나 API 토큰 수를 구독 잔여량으로 환산하지 않습니다.

분석 결과에는 실제 응답의 입력·출력·캐시·추론 토큰을 표시합니다. 공급자가 사용량을 반환하지 않으면 미제공으로 표시합니다. API 비용은 실제 토큰 수와 확인된 모델 요금표로 계산한 **추정 비용**입니다. 캐시·추론 토큰이 입력·출력에 포함되면 중복 합산하지 않습니다. 공급자가 청구 금액을 반환하는 경우에는 해당 값을 사용합니다. 요금표가 없으면 0원으로 표시하지 않습니다. 세금·환율·할인·최종 청구와 다를 수 있습니다.

공식 요금 정보가 포함된 모델 목록과 JSON 요금표를 갱신할 수 있습니다. 계산에 사용한 출처와 기준일을 보관하며, CLI 계정 플랜과 API 청구를 구분합니다.

자세한 원본 형식은 [방송 기록 데이터](timeline-data.ko.md), 개발과 검증은 [개발 가이드](development.ko.md)를 참고하세요.

## 모델 목록 조회

설치된 CLI를 찾거나 설치·로그인한 뒤 **모델 → 목록 조회**를 누릅니다. Codex는 app-server의 model/list, Claude는 초기화 제어 응답, Grok·Antigravity는 모델 목록 명령, Kimi는 ACP 세션 메타데이터에서 모델을 가져옵니다. 모델 요청 프롬프트를 보내거나 유료 추론을 시작하지 않습니다. 조회 실패 시 임의의 기본 목록으로 바꾸지 않습니다.

API는 키를 입력한 다음 목록 조회를 누르면 키를 암호화해 저장하고 해당 서비스의 모델 목록을 가져옵니다. 모델·추론 강도를 골라 **연결 저장**을 누릅니다. 분석 화면에서는 AI 연결과 요청·범위만 선택합니다.

## GitHub 연결 구성요소

![AI 연결 모듈 설정 화면](assets/screenshots/ai-connectors.png)

LLM별 구현은 별도 공개 저장소 [streamer-assist-ai-connectors](https://github.com/yechankun/streamer-assist-ai-connectors)에서 배포합니다. openai-v0.1.0, anthropic-v0.1.0처럼 각 LLM의 버전과 릴리즈 태그를 독립적으로 관리합니다. 앱 설치 프로그램에는 공통 실행기·암호화 설정과 결과·다운로드 관리자만 포함하며, 제공자 어댑터 소스와 CLI 바이너리는 제외합니다.

설정 → AI 연결의 **+**에서 필요한 AI를 추가합니다. 목록의 **×**로 연결을 제거하면 설정 카드도 사라집니다. 저장된 암호화 키와 연결 모듈은 재추가를 위해 보관합니다. 내려받은 모듈까지 삭제하려면 해당 AI의 **연결 모듈 → 연결 모듈 제거**를 사용합니다. 같은 화면에서 버전 확인·업데이트·이전 버전 복원을 지원합니다. PC에 설치된 CLI는 별도로 관리합니다. 원본 CLI 파일은 공식 배포처에서 받으며 별도 저장소에는 이 프로젝트의 연동 코드를 배포합니다.

다운로드가 실패하면 연결 모듈 카드에 실패 단계와 공개 HTTP 상태 또는 파일 작업 오류 코드를 표시합니다. 연결을 지우지 않고 **다운로드·추가**로 다시 시도할 수 있습니다.

앱은 지정된 GitHub 저장소의 릴리즈만 사용합니다. GitHub 릴리즈 자산의 SHA-256과 카탈로그·패키지의 해시를 대조하고 파일별 해시와 공통 실행기 버전 호환성을 확인합니다. 설치를 완료한 뒤 활성화하며 실패하면 기존 버전을 유지합니다. 이미 검증해 설치한 모듈은 오프라인에서도 사용합니다. 연결 모듈의 정보와 인증 정보는 별도로 보관하고 공개 모듈 다운로드에 개인 GitHub 토큰을 요구하지 않습니다.

LLM별 릴리즈는 자체 GitHub Actions 검사 후 패키지를 등록하고 공통 카탈로그를 갱신합니다. CLI 인수·출력 해석·모델 조회·API 매핑·요금표·원본 다운로드 규칙은 데스크톱 앱을 다시 빌드하지 않고 해당 모듈만 업데이트할 수 있습니다. 공통 실행기의 인터페이스 변경은 앱 업데이트가 필요합니다.
