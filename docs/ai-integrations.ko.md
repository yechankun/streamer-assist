# AI 연결과 채팅 분석

[English](ai-integrations.md) · [사용 가이드](user-guide.ko.md) · [제품 소개](../README.ko.md)

방송 채팅의 질문·반응·주요 흐름을 AI로 정리할 때 사용합니다. AI 연결 없이도 기록·추첨·투표·로컬 통계는 사용할 수 있습니다.

## 처음 분석하기

1. **설정 → AI 연결 → +**에서 사용할 AI를 추가합니다.
2. **CLI**는 실행 파일을 설치하거나 찾은 뒤 로그인합니다. **API**는 키를 연결합니다.
3. 모델을 조회하고 **기능별 AI**에서 사용할 AI·모델을 선택합니다. 선택하면 자동 저장합니다.
4. **방송 타임라인 → AI 분석**에서 기능과 기록 범위를 고르고, 전송량을 확인한 뒤 실행합니다.

연결할 AI는 Codex·Claude·Grok·Antigravity·DeepSeek·Kimi 중 선택할 수 있습니다.

[AI 분석 화면](assets/screenshots/ai-analysis.png)은 왼쪽에 기능·범위·질문 입력, 오른쪽에 결과를 표시합니다. 사용할 AI가 지정되지 않으면 안내 패널의 **AI 지정하기**로 설정을 엽니다. 상단 **기능별 AI 설정**에서도 변경할 수 있습니다. 다른 타임라인 화면으로 전환해도 탭 메뉴 위치는 유지됩니다.

## 지원 방식

| 방식 | 연결 방법 | 요금·권한 |
| --- | --- | --- |
| **CLI** | 설치한 AI 도구에서 계정 로그인 | 해당 CLI 계정 플랜과 한도 사용 |
| **API** | 공급자 콘솔에서 발급한 키 연결 | 별도 API 권한·사용량 요금 적용 |

Codex·Claude·Grok·Kimi는 앱 전용 로그인 프로필을 사용합니다. Antigravity는 **PC 로그인 공유**를 직접 허용해야 하며 PC의 공용 세션에 적용됩니다. DeepSeek의 CLI 연결도 API 키를 사용합니다.

<details>
<summary>서비스별 CLI·API와 모델 지원</summary>

| 서비스 | CLI | API |
| --- | --- | --- |
| OpenAI | [Codex](https://developers.openai.com/codex/noninteractive), 앱 전용 CLI 로그인 | OpenAI Responses API |
| Anthropic | [Claude Code](https://code.claude.com/docs/en/headless), 앱 전용 CLI 로그인 | Claude Messages API |
| xAI | [Grok Build](https://docs.x.ai/build/cli/headless-scripting) | xAI Chat Completions |

| DeepSeek | [공식 안내의 Codex 연결](https://api-docs.deepseek.com/quick_start/agent_integrations/codex/) · DeepSeek API 키 사용 | DeepSeek Chat Completions |
| Moonshot | [Kimi Code CLI](https://www.kimi.com/code/docs/en/kimi-code-cli/reference/kimi-command.html) | Kimi/Moonshot Chat Completions |

CLI 구독과 API 키의 이용 권한·요금은 각각 다릅니다. 모델은 직접 입력하지 않습니다. CLI의 모델 조회 명령·제어 프로토콜 또는 API의 모델 목록에서 실제 조회한 항목만 선택합니다. 모델과 추론 수준은 설정 → AI 연결 → **기능별 AI**에서 지정합니다. 연결 관리의 기본 모델은 초기 선택용이며 실제 실행은 기능에 지정한 설정을 사용합니다. 지원되는 모델의 추론 옵션만 선택할 수 있으며, 서비스 기본값을 고르면 옵션을 강제로 바꾸지 않습니다. CLI나 모델이 필수 실행 옵션을 지원하지 않으면 실패 이유를 표시합니다.

</details>

## 기능별 설정

| 원하는 분석 | 기능 그룹 |
| --- | --- |
| 자유 요청·질문 정리·반응 분석 | 채팅 분석 |
| 방송 요약·하이라이트 | 방송 정리 |
| 후원 요약 | 후원 분석 |

먼저 그룹의 AI·모델을 고르면 그 그룹의 기능이 함께 사용합니다. 특정 기능만 다르게 쓰려면 **그룹 따르기**를 끄고 개별 설정을 고릅니다. 다시 켜면 그룹 설정으로 돌아갑니다.

설정은 선택 즉시 저장합니다. **개별 기능 → 그룹 → 전체 기본값** 순서로 적용하며 **AI 사용 안 함**으로 분석을 끌 수 있습니다.

<details>
<summary>상속·사용 안 함·연결 해제 시 동작과 화면</summary>

| 그룹 | 기능 |
| --- | --- |
| 채팅 분석 | 자유 분석, 질문 정리, 반응 분석 |
| 방송 정리 | 방송 요약, 하이라이트 |
| 후원 분석 | 후원 요약 |

AI·모델·추론 수준을 목록의 선택 상자에서 바로 지정하면 자동으로 저장됩니다. 별도 모달이나 적용 버튼은 없습니다. **그룹 따르기**는 기본으로 켜져 있으며, 끄면 현재 값을 개별 설정으로 유지합니다. 그룹을 변경하면 토글이 켜진 기능만 따라 바뀝니다. 다시 켜면 개별 설정을 지우고 그룹의 최신 값을 사용합니다. 로그인한 CLI 또는 저장된 API 연결과 해당 연결에서 조회한 모델만 선택할 수 있습니다. **전체 기본값 설정**도 같은 화면에서 지정하며, **전체 기본값 사용**은 그룹 설정을 해제합니다.

로그아웃하거나 연결을 제거하면 지정한 설정을 유지한 채 사용 불가 이유를 표시합니다. 다른 AI나 요금 방식으로 자동 대체하지 않습니다. 분석 요청에는 기능을 지정하며 서버가 실제 AI·방식·모델·추론 수준을 결정하고 실행 시점의 설정을 기록합니다. 진행 중 설정을 변경해도 이미 실행한 분석의 모델은 바뀌지 않습니다. 기존의 사용 가능한 연결 설정은 전체 기본값으로 옮깁니다.

**AI 사용 안 함**은 전체·그룹·개별 기능의 AI 선택 목록에 있습니다. 그룹에서 끄면 그룹 설정을 따르는 기능만 사용을 중지하고, 개별 설정은 유지합니다. 사용 안 함으로 지정한 기능은 다른 AI로 대체하거나 분석 요청을 보내지 않습니다.

![그룹별 기능 설정](assets/screenshots/ai-functions.png)

1240 × 850 네이티브 화면 캡처입니다. 모델·계정은 테스트용이며 실제 로그인이나 유료 요청은 사용하지 않았습니다.

## 전송 범위와 결과

실행 전에 기록 범위와 **전송 건수 / 전체 건수**를 확인하세요. 입력 한도를 넘으면 범위 전체에서 일부 기록을 골라 보내고 샘플링 여부를 표시합니다.

기본값은 닉네임을 가명으로 바꾸고 공개 계정 ID를 제외합니다. **채팅 본문에 적힌 개인정보는 유지합니다.**

진행 중 요청은 중지할 수 있습니다. 결과는 PC에 암호화해 보관하며 다시 열거나 삭제할 수 있습니다. 원본 채팅과는 별도로 관리합니다.

<details>
<summary>전송 내용·샘플링·보관 정책</summary>

전체 선택 범위를 읽어 건수를 집계하고, 입력 한도를 넘으면 기간 전체에서 결정적 샘플을 고릅니다. 화면에 **전송하는 기록 수 / 전체 기록 수**, 용량, 대략적인 토큰 수, 샘플링 여부를 표시합니다. 모델의 실제 토큰 수는 응답 후 제공되는 사용량으로 확인합니다. 샘플 분석을 전체 원문 분석으로 표시하지 않습니다.

기본값은 공개 닉네임을 가명으로 바꾸고 공개 계정 ID를 제외합니다. 같은 화자를 연결하는 분석용 ID, 플랫폼, 시점, 본문은 유지합니다. 본문에 적힌 개인정보는 자동 삭제하지 않습니다. 공개 식별 정보 포함은 직접 선택합니다. 시청자 채팅을 실행 지시로 취급하지 않으며 AI 출력도 텍스트로만 표시합니다.

API 키와 결과는 Windows 보안 저장소로 암호화합니다. 저장된 키를 화면으로 다시 반환하지 않습니다. 요청 중지, 저장된 결과 선택·삭제를 지원합니다. 결과는 제한된 수로 보관하며 원본 채팅과 별도로 관리합니다. 외부 서비스나 CLI 자체 로그의 보관 정책은 해당 서비스가 관리합니다.

</details>

## 사용량·한도·요금

결과에서 사용량과 확인 가능한 CLI 한도·API 추정 비용을 봅니다. 공급자가 정보를 주지 않으면 **미제공**으로 표시합니다.

API 추정 비용은 최종 청구와 다를 수 있습니다. CLI 구독 한도와 API 요금은 별도로 확인하세요.

<details>
<summary>토큰·캐시·요금 계산 기준</summary>

CLI는 공식 출력이나 공식 읽기 전용 프로토콜에서 제공한 한도를 표시합니다. Codex는 세션·주간 창과 초기화 시각을 조회하며, 다른 CLI는 제공되는 한도 이벤트를 표시합니다. 서비스가 외부 조회를 제공하지 않으면 조회 불가 이유를 표시합니다. CLI 한도를 추측하거나 API 토큰 수를 구독 잔여량으로 환산하지 않습니다.

분석 결과에는 실제 응답의 입력·출력·캐시·추론 토큰을 표시합니다. 공급자가 사용량을 반환하지 않으면 미제공으로 표시합니다. API 비용은 실제 토큰 수와 확인된 모델 요금표로 계산한 **추정 비용**입니다. 캐시·추론 토큰이 입력·출력에 포함되면 중복 합산하지 않습니다. 공급자가 청구 금액을 반환하는 경우에는 해당 값을 사용합니다. 요금표가 없으면 0원으로 표시하지 않습니다. 세금·환율·할인·최종 청구와 다를 수 있습니다.

공식 요금 정보가 포함된 모델 목록과 JSON 요금표를 갱신할 수 있습니다. 계산에 사용한 출처와 기준일을 보관하며, CLI 계정 플랜과 API 청구를 구분합니다.

자세한 원본 형식은 [방송 기록 데이터](timeline-data.ko.md), 개발과 검증은 [개발 가이드](development.ko.md)를 참고하세요.

</details>

## 구성요소 관리

로그인된 CLI는 **로그인 완료**로 표시합니다. 계정을 바꾸려면 먼저 로그아웃하세요. API 키는 **API 키 관리**에서 변경합니다.

CLI 설치·업데이트는 **설치 관리**, 연결 모듈은 **고급 관리**에서 확인합니다. 업데이트는 새 버전이 확인되었을 때 사용할 수 있습니다. 기존 PC의 외부 CLI는 앱에서 삭제하지 않습니다.

<details>
<summary>로그인·로그아웃·버전 관리의 상세 동작</summary>

**다운로드·설치**로 앱 프로필의 `ai/components/`에 CLI를 준비합니다. **설치 관리**를 펼치면 **설치 찾기**로 PC의 기존 CLI를 찾거나 버전 확인·업데이트·이전 버전 복원·제거를 할 수 있습니다. 연결 모듈은 **고급 관리**에서 별도로 관리합니다. PC에 따로 설치한 CLI는 앱에서 삭제하지 않습니다.

로그인된 CLI는 **로그인 완료**로 표시하며 로그인 버튼이 비활성화됩니다. 계정을 바꾸려면 로그아웃 후 다시 로그인합니다. 연결된 API는 **API 키 관리**에서 키를 변경할 수 있습니다. AI를 선택하거나 관리 화면을 열면 CLI·연결 모듈의 최신 버전을 자동으로 확인하며, 조회 결과는 5분간 재사용합니다. **업데이트**는 설치된 버전보다 높은 새 버전이 확인된 경우에만 활성화됩니다. 최신·확인 중·확인 실패·외부 CLI 버전 불명 상태에서는 비활성화하고 이유를 표시합니다. **버전 확인**으로 다시 조회할 수 있습니다.

CLI 설치·업데이트 전에 연결 모듈의 다운로드 방식을 최신 버전으로 갱신합니다. Grok의 공식 Windows 패키지는 Brotli로 압축된 실행 파일을 포함하므로, 아카이브의 SHA-512를 검증한 뒤 용량 제한을 적용해 압축을 해제합니다. CLI 실행 파일은 앱 설치 프로그램에 포함하지 않습니다.

**로그인**은 앱 안의 계정 연결 창에서 실제 인증 절차를 시작합니다. Codex·Claude·Grok·Kimi는 로그인·모델 조회·사용량·분석에 앱 전용 프로필을 사용하며, 기존 PC 인증 정보를 복사하지 않습니다. 새 로그인 전에 실행하는 공식 로그아웃도 앱 전용 프로필에만 적용합니다. 전용 프로필을 처음 적용하면 CLI에 다시 로그인해야 하며 API 연결은 유지합니다. 인증 중 대기·완료·실패·취소 상태와 CLI가 제공하는 일회용 코드를 표시합니다.

연결 모듈은 각 CLI가 공식 지원하는 프로필 변수를 제공합니다. Codex는 [CODEX_HOME과 파일 인증 저장소](https://learn.chatgpt.com/docs/auth), Claude는 Claude·Anthropic 두 프로필, Grok·Kimi는 공식 데이터 경로 설정을 이용합니다. CLI 인증 정보는 해당 CLI의 저장 형식을 따르며, 앱의 API 키는 Windows 보안 저장소에 암호화합니다.

Antigravity는 [OS의 공용 인증 저장소](https://www.antigravity.google/docs/cli/install/)를 사용하며 별도 인증 영역을 지정하는 공식 설정을 확인하지 못했습니다. Google API 방식은 앱 안에서 인증 정보를 관리합니다. Antigravity를 사용하려면 CLI 설정에서 **PC 로그인 공유**를 직접 켜야 하며 로그인·로그아웃은 PC의 공용 세션에 적용됩니다. 앱은 로그인 중 공식 `/usage` 응답을 자동으로 확인하며, 이 조회는 분석 요청이나 토큰 사용 없이 인증을 검증합니다. 인증이 확인되면 대기가 끝나고 **모델 조회하고 계속**으로 실제 사용 가능한 모델을 가져옵니다. 대기 중 **로그인 완료 확인**으로 직접 확인할 수도 있습니다. 창이 열리거나 닫혔다는 이유만으로 성공을 표시하지 않으며, 취소한 작업은 늦게 도착한 확인 결과로 성공 처리되지 않습니다.

**로그아웃**으로 모델 선택·연결·한도를 초기화합니다. 격리를 지원하는 CLI는 앱 전용 프로필에서만 로그아웃합니다. Kimi는 공식 ACP의 로그아웃 지원 여부와 응답을 확인합니다. 공유를 직접 허용한 Antigravity 연결은 열린 CLI에서 `/logout`을 실행한 뒤 창을 닫고 앱에서 완료를 확인합니다. API 방식과 DeepSeek 연결은 앱에 암호화해 저장한 키를 해제하며, 별도로 사용하는 브라우저의 로그인은 유지합니다. 설치·업데이트·제거는 실제 작업이 끝난 뒤 완료로 표시하고, 진행 중인 같은 구성요소 작업을 중복 실행하지 않습니다.

로그아웃 버튼은 로그인·모델 조회로 확인한 CLI 연결이나 저장된 API 키가 있을 때 표시합니다. 앱에서 해당 연결을 해제하면 버튼이 사라지고, 앱을 다시 열어도 해제 상태를 유지합니다. CLI와 API의 로그인 상태는 따로 관리합니다.

DeepSeek의 CLI 연결과 각 서비스의 API는 **API 키 연결 / API 연결 창 열기**에서 공식 콘솔을 열고 키를 저장합니다. 저장 후 실제 모델 목록을 조회해 연결을 확인하며, 분석 요청을 보내지 않습니다. CLI OAuth 토큰과 계정 비밀번호는 앱이 직접 입력받거나 화면에 반환하지 않습니다. 이전 연결 모듈에 로그인 절차가 없으면 연결 모듈 업데이트를 안내합니다.

![AI 계정 연결 창](assets/screenshots/ai-login.png)

실제 Electron 창의 격리 테스트 캡처입니다. 인증 결과는 가상 CLI 응답으로 재현하며 실제 계정에 로그인하지 않습니다.

CLI 실행 파일은 설치 프로그램과 ASAR에 포함하지 않습니다. 공식 릴리즈 메타데이터에서 버전을 확인하고 SHA-256/SHA-512로 다운로드를 검증합니다. 설치 중 취소·오류가 나면 기존 버전을 유지합니다. API 연결은 공통 HTTP 실행기를 사용하므로 서비스별 SDK를 추가로 설치하지 않습니다. 사용하지 않는 연결을 해제하거나 직접 추가한 연결을 제거할 수 있습니다.

연결 목록의 **+** 버튼에서 JSON 연결 파일을 가져올 수 있습니다. 새 호환 API는 설치된 연결 모듈의 프로토콜 구현을 사용하며, HTTPS와 로컬 localhost 주소를 지원합니다. 이 파일은 주소와 호환성 메타데이터만 포함합니다. 실행 가능한 연결 모듈은 아래의 고정된 GitHub 저장소에서 검증 후 설치합니다.

```json
{
  "schemaVersion": 1,
  "id": "custom-local-model",
  "name": "로컬 AI",
  "protocol": "chat",
  "baseUrl": "http://127.0.0.1:1234/v1",
  "models": []
}
```

모델별 추론 옵션 변경은 type: model-capabilities 파일로 갱신할 수 있습니다. 이 메타데이터만으로 선택 가능한 모델을 추가하지 않으며, 모델 목록은 연결된 API에서 조회합니다. CLI 실행 플래그·출력 프로토콜 변경은 해당 연결 모듈 업데이트로 대응합니다. 공통 호스트 ABI가 바뀌는 경우 앱 업데이트가 필요합니다.

## 모델 목록 조회

모델이 보이지 않으면 로그인 후 **목록 조회**를 누릅니다. 로그인 창의 **모델 조회하고 계속**, API 창의 **저장하고 연결 확인**으로도 가져올 수 있습니다.

실제로 조회한 모델과 지원되는 추론 수준만 선택합니다. 분석 화면의 **AI 지정하기**는 해당 기능의 설정으로 이동합니다.

<details>
<summary>모델 조회 프로토콜과 연결 기본 모델</summary>

설치된 CLI를 찾거나 설치·로그인한 뒤 **모델 → 목록 조회**를 누릅니다. Codex는 app-server의 model/list, Claude는 초기화 제어 응답, Grok·Antigravity는 모델 목록 명령, Kimi는 ACP 세션 메타데이터에서 모델을 가져옵니다. 모델 요청 프롬프트를 보내거나 유료 추론을 시작하지 않습니다. 조회 실패 시 임의의 기본 목록으로 바꾸지 않습니다.

CLI 로그인 창에서 **모델 조회하고 계속**, API 연결 창에서 **저장하고 연결 확인**을 눌러도 모델을 가져옵니다. API 연결 화면에서 키를 입력하고 **목록 조회**를 누르면 키를 암호화해 저장한 뒤 실제 모델 목록을 확인합니다. 모델·추론 수준을 골라 **연결 저장**으로 연결의 기본 모델을 저장합니다.

실제 분석 설정은 **기능별 AI**에서 적용합니다. 그룹·기능 행의 **AI 연결**, 모델, 추론 수준을 고릅니다. 모델을 갱신하려면 **새로고침**을 누릅니다. 분석 화면에서는 **분석 기능**과 요청·범위만 선택하며 적용된 연결·모델·추론 수준을 표시합니다. **기능별 AI 설정** 또는 **AI 지정하기**는 해당 그룹의 목록으로 이동하고 선택한 기능을 표시합니다.

</details>

## GitHub 연결 구성요소

필요한 연결 모듈은 AI를 추가할 때 내려받습니다. **×**로 목록에서 제거해도 저장된 키와 모듈은 재추가를 위해 보관합니다. 파일까지 지우려면 **고급 관리 → 연결 모듈 제거**를 사용하세요.

공급자 호환성 변경은 연결 모듈을 업데이트해 반영합니다. 설치·다운로드에 문제가 있으면 표시된 이유를 확인하고 다시 시도하세요.

<details>
<summary>배포 저장소·검증·오프라인 재사용</summary>

![사용할 AI와 연결 모듈을 추가하는 선택창](assets/screenshots/ai-connectors.png)

LLM별 구현은 별도 공개 저장소 [streamer-assist-ai-connectors](https://github.com/yechankun/streamer-assist-ai-connectors)에서 배포합니다. openai-v0.1.0, anthropic-v0.1.0처럼 각 LLM의 버전과 릴리즈 태그를 독립적으로 관리합니다. 앱 설치 프로그램에는 공통 실행기·암호화 설정과 결과·다운로드 관리자만 포함하며, 제공자 어댑터 소스와 CLI 바이너리는 제외합니다.

설정 → AI 연결의 **+**에서 필요한 AI를 추가합니다. 목록의 **×**로 연결을 제거하면 설정 카드도 사라집니다. 저장된 암호화 키와 연결 모듈은 재추가를 위해 보관합니다. 내려받은 모듈까지 삭제하려면 해당 AI의 **고급 관리 → 연결 모듈 제거**를 사용합니다. 같은 화면에서 버전 확인·업데이트·이전 버전 복원을 지원합니다. PC에 설치된 CLI는 별도로 관리합니다. 원본 CLI 파일은 공식 배포처에서 받으며 별도 저장소에는 이 프로젝트의 연동 코드를 배포합니다.

다운로드가 실패하면 연결 모듈 카드에 실패 단계와 공개 HTTP 상태 또는 파일 작업 오류 코드를 표시합니다. 연결을 지우지 않고 **다운로드·추가**로 다시 시도할 수 있습니다.

앱은 지정된 GitHub 저장소의 릴리즈만 사용합니다. 배포 CI가 GitHub API의 자산 SHA-256을 실제 파일과 대조한 뒤, 같은 저장소의 `distribution-v1/index.json`에 검증 결과를 게시합니다. 앱은 고정된 GitHub HTTPS 경로의 게시자와 이 메타데이터를 신뢰하며 저장소·태그·파일 주소·카탈로그·패키지·파일별 해시와 ABI를 검증합니다. 별도 전자서명이나 사용자의 GitHub API 조회로 인증하는 방식은 아닙니다. 공개 배포 메타데이터를 사용하므로 사용자의 익명 REST 요청 한도와 개인 GitHub 토큰에 의존하지 않습니다.

Windows의 일시적인 파일 잠금은 제한된 간격으로 재시도합니다. 활성 파일을 먼저 삭제하지 않으며 실패하면 기존 설치를 유지합니다. 개발 서버는 프로필·다운로드 임시 폴더를 감시하지 않습니다. 설치된 모듈과 Windows 암호화로 보호된 검증 메타데이터는 오프라인에서도 재사용합니다. 기존 REST 조회 방식이 필요한 경우에는 403의 요청 제한 초기화 시각을 따르며 즉시 반복 요청하지 않습니다.

LLM별 릴리즈는 자체 GitHub Actions 검사 후 패키지를 등록하고 공통 카탈로그를 갱신합니다. CLI 인수·출력 해석·모델 조회·API 매핑·요금표·원본 다운로드 규칙은 데스크톱 앱을 다시 빌드하지 않고 해당 모듈만 업데이트할 수 있습니다. 공통 실행기의 인터페이스 변경은 앱 업데이트가 필요합니다.

</details>
