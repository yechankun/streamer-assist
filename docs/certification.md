# Streamer Assist 심사용 안내

이 앱은 방송 타임라인·채팅 반응 감지·시청자 추첨·숫자 투표·후원 메시지 투표·가중치 룰렛을 제공하는 Windows 데스크톱 도구입니다. 한국어 UI를 제공하며 치지직·YouTube·트위치의 공식 앱이 아닙니다.

## 계정 없이 기능 체험

1. 홈에서 **방송 타임라인**으로 이동하고 **방송 기록 시작**을 누릅니다.
2. **설정 → 일반 → 테스트 채팅**을 켭니다. 실제 플랫폼 연결과 분리된 모의 메시지를 생성합니다.
3. **시청자 추첨**에서 아무 채팅 또는 !참여 키워드 모집을 시작합니다. 구독자·멤버십 조건, 이전 당첨자 제외와 타이머를 확인한 뒤 추첨합니다.
4. **숫자 투표**에서 빈 질문·선택지 입력칸에 값을 넣고 추가 버튼/Enter로 선택지를 2~4개 만듭니다. 투표를 시작하면 방송용 현황으로 전환됩니다. !투표1 등의 테스트 채팅이 집계됩니다.
5. **도네 투표**는 최소 금액·1인 1표 또는 금액 배수·통화·타이머를 설정합니다. 테스트 채팅에서는 모의 후원만 발생하며 실제 결제는 없습니다.
6. 투표 종료 후 **결과로 룰렛**으로 득표수를 전달하거나, **룰렛**에서 독립적으로 항목·가중치를 입력해 회전과 당첨 결과를 확인합니다.
7. 타임라인의 동접 그래프, **채팅·후원** 전체 날짜/플랫폼 필터, **날짜·용량 관리** 일·주·월 선택을 확인합니다. **분석·AI 데이터**에서 로컬 통계·JSONL을 확인하고 방송 종료 후 마커를 Markdown/JSON으로 내보냅니다. **정보·데이터**에서 개인정보처리방침과 기록 삭제를 확인합니다.

## 선택적 AI 연결·분석 확인

1. **설정 → AI 연결 → +**에서 사용할 AI를 선택합니다. 연결 모듈과 CLI 실행 파일은 별도로 준비하며 앱 설치 프로그램에 공급자 구현이나 CLI를 포함하지 않습니다.
2. CLI 로그인 또는 API 키 연결 후 실제 모델 목록을 조회합니다. Codex·Claude·Grok·Kimi는 앱 전용 로그인 프로필을 사용합니다. Antigravity는 **PC 로그인 공유**를 직접 허용하면 공용 세션에 로그인·로그아웃합니다.
3. **기능별 AI**에서 전체·그룹 기본값과 개별 기능 설정을 확인합니다. 3개 그룹·6개 기능을 지원하며 개별 기능 → 그룹 → 전체 기본값 순서로 적용합니다. 연결을 해제하면 사용 불가 이유를 표시합니다.
4. **방송 타임라인 → AI 분석**에서 기능·범위를 선택하고 실제 적용되는 AI·모델·추론 수준, 전송 건수와 샘플링을 확인합니다. 실행 버튼을 누르면 외부 CLI/API를 호출하므로 실제 서비스 연결과 사용 권한이 필요하고 API 요금이 발생할 수 있습니다.
5. 중지·결과 다시 열기/삭제·사용량·제공되는 CLI 한도·API 추정 비용을 확인합니다. 기본 전송은 가명 처리하지만 채팅 본문 속 개인정보는 유지합니다.

테스트 채팅은 원본 기록과 참여 기능의 체험용이며 AI 계정 인증을 대신하지 않습니다. 문서의 AI 화면은 가상 인증·모델을 사용하는 격리 테스트 캡처입니다. 실제 계정이나 유료 요청을 사용한 검증 결과가 아닙니다.

## 실제 플랫폼 연동

- 치지직은 공개 방송 채널 주소로 읽기 전용 채팅에 연결합니다. 로그인 제한 방송은 지원하지 않습니다.
- YouTube는 기본 브라우저의 Google Desktop OAuth 로그인과 사용자 동의를 이용합니다. 방송 채널 소유자의 계정과 활성 방송이 필요합니다. 실제 로그인 확인용 테스트 계정·방송 환경이 필요하면 제출자의 Partner Center 심사 메모에 별도로 제공합니다. 개인 계정 비밀번호나 토큰을 이 문서에 적지 않습니다.
- 개발자 앱의 YouTube Data API 활성화·공개 OAuth 동의 화면 준비·필요한 Google 검증은 Store 심사와 별개입니다.
- 트위치는 Public 앱의 Client ID 설정 후 기본 브라우저의 Device Code 인증으로 본인 채널의 채팅 읽기를 승인합니다. 공식 EventSub WebSocket을 사용하며 채팅 하이라이트·구독자 추첨·숫자 투표를 지원합니다. Bits 도네 투표와 트위치 기본 투표는 아직 지원하지 않습니다. 실제 OAuth·방송 수신은 별도 검증이 필요합니다.
- 일반 채팅은 후원 투표에 포함되지 않습니다. 치지직 치즈는 KRW, 슈퍼챗은 지정한 통화만 집계합니다. 계정 연결 해제는 저장된 연결을 제거합니다.

## MSIX 권한·동작 설명

- `runFullTrust`: Electron/Node 데스크톱 실행, 전역 타임라인 단축키, 트레이와 사용자 선택 파일 내보내기에 필요합니다.
- `internetClient`: 사용자가 선택한 플랫폼 API·브라우저 로그인, AI 연결 모듈/CLI 다운로드와 선택적 AI 분석에 필요합니다.
- `windows.startupTask`: 기본 비활성입니다. 앱 설정에서 Windows의 시작 앱 설정을 열어 사용자가 관리합니다.
- 창의 X는 트레이 설정에 따라 숨기거나 종료합니다. 완전 종료는 트레이 메뉴 또는 트레이 사용을 끈 뒤 창 닫기로 확인합니다. 데이터는 종료 전 암호화 저장합니다.

## 제출 자료

개인정보처리방침: https://yechankun.github.io/streamer-assist/privacy.html

첫 제출은 Partner Center에서 앱 이름 예약·패키지 식별자·연령 등급·스토어 설명·스크린샷을 입력합니다. 게시 이후 버전 태그에서 CI가 MSIX를 생성하고 Store 제출 API로 업데이트합니다. 승인·공개 시점은 Microsoft 심사 결과에 따릅니다.

CI의 개발용 MSIX는 Store 식별자가 없는 검증용 패키지입니다. 서명되지 않았으며 일반 사용자의 직접 설치용이 아닙니다. 정식 Store 업로드는 예약한 Identity Name/Publisher/제품 ID가 일치하는 패키지로 수행합니다.

## 기록·분석과 제출 버전

원문 채팅·후원·참여자·동접은 삭제 전까지 암호화 보관합니다. 날짜별 삭제는 용량 확인과 진행 중 날짜 보호를 제공하며 JSONL은 AI 분석용 가명 데이터를 내보냅니다. 선택적 CLI/API 분석은 사용자가 실행할 때만 호출합니다. AI 설치·로그인·전송 범위·중지·사용량 표시와 개인정보 안내를 제출 패키지에서 확인합니다. 이 문서는 현재 개발 구현의 안내이므로 설명·캡처는 실제 제출 패키지와 일치시킵니다. 공개 v0.1.0 MVP에는 일부 기능이 없을 수 있습니다.
