# Streamer Assist 심사용 안내

이 앱은 방송 타임라인·채팅 반응 감지·시청자 추첨·숫자 투표·후원 메시지 투표·가중치 룰렛을 제공하는 Windows 데스크톱 도구입니다. 한국어 UI를 제공하며 치지직·YouTube의 공식 앱이 아닙니다.

## 계정 없이 기능 체험

1. 홈에서 **방송 타임라인**으로 이동하고 **방송 기록 시작**을 누릅니다.
2. **설정 → 일반 → 테스트 채팅**을 켭니다. 실제 플랫폼 연결과 분리된 모의 메시지를 생성합니다.
3. **시청자 추첨**에서 아무 채팅 또는 !참여 키워드 모집을 시작합니다. 구독자·멤버십 조건, 이전 당첨자 제외와 타이머를 확인한 뒤 추첨합니다.
4. **숫자 투표**에서 빈 질문·선택지 입력칸에 값을 넣고 추가 버튼/Enter로 선택지를 2~4개 만듭니다. 투표를 시작하면 방송용 현황으로 전환됩니다. !투표1 등의 테스트 채팅이 집계됩니다.
5. **도네 투표**는 최소 금액·1인 1표 또는 금액 배수·통화·타이머를 설정합니다. 테스트 채팅에서는 모의 후원만 발생하며 실제 결제는 없습니다.
6. 투표 종료 후 **결과로 룰렛**으로 득표수를 전달하거나, **룰렛**에서 독립적으로 항목·가중치를 입력해 회전과 당첨 결과를 확인합니다.
7. 방송 종료 후 기록을 Markdown/JSON으로 내보낼 수 있습니다. **정보·데이터**에서 개인정보처리방침과 기록 삭제를 확인합니다.

## 실제 플랫폼 연동

- 치지직은 공개 방송 채널 주소로 읽기 전용 채팅에 연결합니다. 로그인 제한 방송은 지원하지 않습니다.
- YouTube는 기본 브라우저의 Google Desktop OAuth 로그인과 사용자 동의를 이용합니다. 방송 채널 소유자의 계정과 활성 방송이 필요합니다. 실제 로그인 확인용 테스트 계정·방송 환경이 필요하면 제출자의 Partner Center 심사 메모에 별도로 제공합니다. 개인 계정 비밀번호나 토큰을 이 문서에 적지 않습니다.
- 개발자 앱의 YouTube Data API 활성화·공개 OAuth 동의 화면 준비·필요한 Google 검증은 Store 심사와 별개입니다.
- 일반 채팅은 후원 투표에 포함되지 않습니다. 치지직 치즈는 KRW, 슈퍼챗은 지정한 통화만 집계합니다. 계정 연결 해제는 저장된 연결을 제거합니다.

## MSIX 권한·동작 설명

- `runFullTrust`: Electron/Node 데스크톱 실행, 전역 타임라인 단축키, 트레이와 사용자 선택 파일 내보내기에 필요합니다.
- `internetClient`: 사용자가 선택한 치지직·YouTube API와 브라우저 로그인에 필요합니다.
- `windows.startupTask`: 기본 비활성입니다. 앱 설정에서 Windows의 시작 앱 설정을 열어 사용자가 관리합니다.
- 창의 X는 트레이 설정에 따라 숨기거나 종료합니다. 완전 종료는 트레이 메뉴 또는 트레이 사용을 끈 뒤 창 닫기로 확인합니다. 데이터는 종료 전 암호화 저장합니다.

## 제출 자료

개인정보처리방침: https://yechankun.github.io/streamer-assist/privacy.html

첫 제출은 Partner Center에서 앱 이름 예약·패키지 식별자·연령 등급·스토어 설명·스크린샷을 입력합니다. 게시 이후 버전 태그에서 CI가 MSIX를 생성하고 Store 제출 API로 업데이트합니다. 승인·공개 시점은 Microsoft 심사 결과에 따릅니다.

CI의 개발용 MSIX는 Store 식별자가 없는 검증용 패키지입니다. 서명되지 않았으며 일반 사용자의 직접 설치용이 아닙니다. 정식 Store 업로드는 예약한 Identity Name/Publisher/제품 ID가 일치하는 패키지로 수행합니다.
