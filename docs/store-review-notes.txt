Streamer-Assist v0.4.1 is a Korean-language Electron/Node.js Windows desktop utility for broadcast timelines, chat archives, viewer raffles, number/donation votes and weighted roulette. It is independent of CHZZK, YouTube, Twitch and AI vendors. It does not record video/audio or process payments.

Review without accounts or payments:
1. Open 방송 타임라인 and select 방송 기록 시작.
2. Open 설정 -> 일반 -> 테스트 채팅. Generated data demonstrates the tools without connecting a real account.
3. Return to the timeline. Add a marker and inspect viewer samples, 채팅·후원 and 분석·AI 데이터. Keep recording and test chat active while trying the audience tools.
4. Open 시청자 추첨, recruit generated participants and draw. In 숫자 투표, enter a question and add at least two choices, then start the animated result view. 도네 투표 uses generated sample donations in test mode; it does not initiate a payment.
5. Open 룰렛, add weighted entries and spin, or import an ended vote. After trying the tools, stop recording and export. Date/size management and 설정 -> 정보·데이터 provide local record review/deletion and the bundled privacy policy.
6. Use + or the tab context menu for duplicate tabs and separate windows. Tab order/window positions survive restart; platform collection is shared. 설정 -> 일반 -> 글자 크기 offers 95–150% text size. Number/donation votes offer optional automatic closing timers.

Optional external connections:
Real platform reception requires an active broadcast and permissions. YouTube/Twitch use browser authorization; CHZZK uses public read-only chat. Optional AI runs after the user selects a connection, function and scope, then confirms transfer. Models and usage come from the selected connection; vendor fees may apply. No real account credentials are supplied.

Codex, Claude, Grok and Kimi use app-specific CLI profiles. Antigravity's shared PC login requires explicit opt-in. Connectors and CLI runtimes are downloaded/installed on user action and are not bundled in the installer. Archives and app-managed API/platform credentials use Windows protection; CLI credentials follow vendor storage. Chat text may contain personal information.

runFullTrust enables tray, global shortcuts, archives, exports and optional AI CLI child processes with standard user privileges. Startup is disabled by default; MSIX opens Windows Startup Apps settings. Closing a secondary window returns its tabs. The primary window hides when tray/other windows remain; otherwise it saves and exits. The tray menu exits.

Pause keeps records; revoke/delete uses a cancel-default confirmation and retries interrupted cleanup. Other-platform originals and manual markers survive. External AI transfer requires provider/model/scope confirmation. No Google verification approval is claimed.
