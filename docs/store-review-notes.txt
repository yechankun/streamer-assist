Streamer-Assist v0.4.2 is a Korean-language Electron/Node.js Windows desktop utility for broadcast timelines, chat archives, viewer raffles, number/donation votes and weighted roulette. It is independent of CHZZK, YouTube, Twitch and AI vendors. It does not record video/audio or process payments.

Review without accounts or payments:
1. Open 방송 타임라인 and select 방송 기록 시작.
2. Open 설정 -> 일반 -> 테스트 채팅. Generated data demonstrates the tools without connecting a real account.
3. Return to the timeline. Add a marker and inspect viewer samples, 채팅·후원 and 분석·AI 데이터. Keep recording and test chat active while trying the audience tools.
4. Open 시청자 추첨, recruit generated participants and draw. The new result dialog celebrates with fireworks/confetti, shows the last pre-draw chat in gray and follows the winner's new messages in the accent color. Close with 닫기 or Escape. Reduced motion skips effects. In 숫자 투표, enter a question and at least two choices, then start the broadcast result view. 도네 투표 uses generated donations, without making a payment.
5. Open 룰렛, add weighted entries and spin, or import an ended vote. Stop recording and export afterward. Date/size management and 설정 -> 정보·데이터 provide record review/deletion and the privacy policy.
6. Use + or the tab menu for duplicate tabs and separate windows. Layouts survive restart; collection is shared. 설정 -> 일반 -> 글자 크기 offers 95–150% text size. Number/donation votes offer closing timers.

Real reception requires an active broadcast and permissions. YouTube/Twitch use browser authorization; CHZZK uses public read-only chat. YouTube uses the official live API; web replay collection and yt-dlp are not provided. Users explicitly accept terms/privacy/30-day retention and review affected records before connecting/resuming. Pause and revoke/delete are separate. Google login waits up to ten minutes. No verification approval is claimed or account credentials supplied.

Optional AI requires connection/function/scope selection and transfer confirmation. Models/usage come from that connection; vendor fees may apply. Codex, Claude, Grok and Kimi use app-specific CLI profiles; Antigravity shared PC login requires opt-in. Connectors/CLI runtimes are downloaded on user action, not bundled. Archives and app-managed credentials use Windows protection; CLI credentials follow vendor storage. Chat text may contain personal information.

The winner preview keeps the pre-draw chat and latest 50 new messages in memory only, matches platform/account IDs and stops on close. It is not restored on restart. Celebration libraries/licenses are bundled and effects load locally, without remote scripts.

runFullTrust enables tray, shortcuts, archives, exports and optional AI CLI child processes with standard user privileges. Startup is disabled by default; MSIX opens Windows Startup Apps settings. A secondary window returns its tabs on close. The primary window hides when tray/other windows remain; otherwise it saves and exits. The tray menu exits.
