Streamer-Assist v0.4.10 is a Korean Windows broadcast timeline, chat archive, raffle, vote and roulette utility. Independent of the platforms; no video/audio recording or payments.

Account-free review:
1. Start 방송 타임라인 -> 방송 기록 시작 and enable 설정 -> 일반 -> 테스트 채팅. Keep recording/test chat active; no account or payment is needed.
2. In 시청자 추첨, recruit from any chat or a keyword. Change subscriber/previous-winner rules with inline toggles and edit the displayed keyword. Platform icons beside the count may all be off while retaining entrants. Hover the clock, adjust the slider or seconds and confirm a countdown. Untouched previews collapse on exit. Drawing closes recruitment. 다시 모집 retains entrants/history; + 새 추첨 준비 starts a fresh round.
3. Names flow with platform icons. Use −/+ or 가 for name size and the button/F11 for fullscreen. The roster speaker saves new-message TTS across windows/restarts. Open a viewer or winner chat: old messages are not replayed; gray is pre-draw chat and green is new chat. Chat speakers share the setting. Mute/hide/close stops playback. The gear selects/previews Windows/browser voices; online voices require consent. The face icon saves optional pixel-character display.
4. Try 숫자 투표, 도네 투표 and 룰렛 with generated data. Viewer reels animate for 3 seconds and roulette for 4–7 seconds. 설정 -> 일반 -> 추첨·룰렛 연출 controls draws/celebrations independently of Windows reduced motion. Verify winner fireworks/confetti, character breathing and animated roulette previews. Review archive export/deletion in the timeline and 설정 -> 정보·데이터.

runFullTrust supports tray, shortcuts, encrypted local archives, Windows System.Speech and optional user-started AI CLIs. External AI runs only after configuration/confirmation. Real reception needs live broadcasts and platform permission. YouTube uses official live APIs; no web-chat extraction or yt-dlp. No test credentials are supplied.
