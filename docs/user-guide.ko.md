처음에는 테스트 채팅으로 도구를 익히고, 실제 방송을 연결하세요. 화면 언어는 한국어입니다.

[방송 연결](#플랫폼-연결) · [기록 보기](#채팅-기록과-날짜-선택) · [탭·창 배치](#탭과-창-배치)

## 연결 없이 체험하기

1. **방송 타임라인 → 방송 기록 시작**을 누릅니다.
2. **설정 → 일반 → 테스트 채팅**을 켭니다.
3. **시청자 추첨**이나 **숫자 투표**를 열어 시작합니다. 룰렛은 별도로 사용할 수 있습니다.

실제 계정이나 결제 없이 샘플 메시지를 사용합니다. 실제 방송을 연결하기 전에 테스트 채팅을 끄세요.

<details>
<summary>개발 모드에서 체험하기</summary>

`npm run dev`로 실행합니다. **방송 타임라인**에서 기록을 시작하고 **설정 → 일반 → 테스트 채팅**을 켭니다.

모의 이벤트에서 하이라이트·추첨 참여자·후원이 생성됩니다. 테스트 모드에서는 테스트 플랫폼이 나타나며 실제 투표 게시나 후원 결제를 하지 않습니다. 실제 플랫폼을 사용하기 전에 테스트 채팅을 끄세요. 룰렛은 독립적으로 사용할 수 있습니다.

</details>

## 플랫폼 연결

**설정 → 플랫폼 연결**에서 준비합니다.

| 플랫폼 | 연결 방법 |
| --- | --- |
| 치지직 | 공개 채널 주소 또는 채널 ID 입력 |
| YouTube | 방송 채널 소유자 계정으로 브라우저 승인 |
| Twitch | 방송 계정으로 브라우저에서 채팅 읽기 승인 |

참여 도구에는 연결된 플랫폼이 표시됩니다. 실제 방송 중임이 확인되고 채팅이 준비된 플랫폼을 선택하세요. 오프라인·상태 미확인 플랫폼으로는 시작할 수 없습니다.

[플랫폼별 제한](#플랫폼과-제한)도 확인하세요.

<details>
<summary>재연결·인증·개발자 설정</summary>

**설정 → 플랫폼 연결**에서 설정합니다.

| 플랫폼  | 연결 방법                                                                        | 참여 기능                                                                                 |
| ------- | -------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 치지직  | 공개 채널·라이브 주소 또는 채널 ID. 로그인과 개발자 앱 등록이 필요하지 않습니다. | 읽기 전용 채팅, 명령 투표, 추첨과 지원되는 치즈 후원. 참여 안내는 복사해 직접 공지합니다. |
| YouTube | 방송 채널 소유자로 브라우저 로그인 후 진행 중인 방송 채팅을 자동 탐색합니다.     | 채팅 명령, 기본 실시간 투표, 추첨과 지원되는 슈퍼챗 메시지.                               |
| 트위치 | 방송 계정으로 브라우저 Device Code 인증 후 본인 채널에 연결합니다. | 채팅 하이라이트·숫자 투표·구독자 및 Founder 추첨. Bits 도네 투표와 트위치 기본 투표는 아직 지원하지 않습니다. |

직접 빌드하는 YouTube 앱은 [개발자 OAuth 설정](development.ko.md#youtube-oauth)이 필요합니다. 사용자는 브라우저에서 권한을 부여하며 토큰을 직접 입력하지 않습니다. 방송이 없으면 대기하고 **방송 채팅 다시 찾기**로 재탐색합니다.

트위치 앱은 [Public 앱 설정](development.ko.md#트위치-oauth)이 필요합니다. 브라우저에서 Twitch 기기 활성화 페이지를 열면 설정에 표시된 코드로 채팅 읽기를 승인합니다. 앱에서 로그인 취소도 가능합니다. 트위치 채팅은 방송을 켜기 전에도 연결할 수 있습니다. 인증이 만료·해제되면 계정을 다시 연결하세요. 앱의 연결 해제는 저장된 토큰을 삭제하며, Twitch의 연결 설정에서도 권한을 해제할 수 있습니다.

연결된 플랫폼만 참여 버튼으로 나타나며, 실제 방송중인 플랫폼만 선택할 수 있습니다. 오프라인·방송 상태 미확인 버튼은 비활성화되고 실행 요청도 차단합니다. 선택한 플랫폼에 실시간 채팅이 준비되어 있어야 합니다. 시작 후 플랫폼·명령 설정은 고정됩니다. 선택한 플랫폼이 없으면 시작할 수 없습니다.

</details>

## 타임라인과 하이라이트

화면 상단의 **타임라인 · 채팅·후원 · 분석·AI 데이터 · AI 분석 · 다시보기 수집** 탭으로 이동합니다. 탭 메뉴는 방송 기록 패널 위에 있어 화면을 바꿔도 같은 위치를 유지합니다. 창이 좁으면 탭 메뉴를 가로로 스크롤할 수 있습니다. 방송 선택은 오른쪽에서, **채팅·후원**의 방송·날짜 선택은 해당 기록 패널에서 합니다.

동접 그래프의 축 숫자와 시간은 창을 크게 키워도 글자 비율이 유지되며, 설정한 글자 크기를 따릅니다. 키보드로 탭·필터를 이동하면 포커스 테두리가 컨트롤 안쪽에 표시됩니다. [타임라인 화면](assets/screenshots/timeline.png)을 참고하세요.

1. **방송 기록 시작**으로 기록을 시작합니다. 자동으로 시작하려면 **방송 자동 감지**를 켭니다.
2. 다시 보고 싶은 순간에 **마커** 또는 전역 단축키를 누릅니다. 설치 버전 기본 키는 `Ctrl+Shift+F8`입니다.
3. **방송 기록 종료**로 저장합니다. 채팅·동접과 기록한 순간은 계속 조회할 수 있습니다.

모든 창이 같은 기록을 공유합니다. 타임라인 탭을 닫아도 수집은 계속되며, 기록 종료는 모든 창에 적용됩니다. 자동 하이라이트는 채팅 반응으로 찾는 편집 후보입니다.

<details>
<summary>자동 감지·단축키·하이라이트 조건</summary>

방송 기록 시작·종료, 채팅·후원 기록과 시청자 수·마커는 모든 타임라인 탭과 창이 공유합니다. 탭을 추가·복제·분리해도 플랫폼별 공통 수집기만 동작하며 연결이나 수집을 중복해서 만들지 않습니다. 투표·추첨 등 다른 도구도 같은 수집 데이터를 사용합니다. 모든 타임라인 탭을 닫아도 공통 기록은 계속되며, **방송 기록 종료**를 누르면 모든 창의 기록이 함께 종료됩니다. 검색 조건과 표시할 과거 방송 선택은 각 탭에서 따로 설정할 수 있습니다.

타임라인 또는 **설정 → 일반**에서 **방송 자동 감지**를 켭니다. 연결된 채널 중 하나라도 방송 중임이 확인되면 기록을 시작하고, 모든 연결 채널의 종료가 확인되면 저장 후 종료합니다. 조회 오류는 종료로 판단하지 않습니다. 확인된 플랫폼 시작 시각 중 가장 이른 시간을 공통 시간축으로 쓰며, 시각이 없으면 감지 시각을 사용합니다. 수집은 앱이 채팅을 받기 시작한 시점부터이며 이전 누락 채팅을 복원하지 않습니다.

수동 기록도 가능합니다. 제목과 경과 초를 입력해 **방송 기록 시작**을 누릅니다. 30분은 `1800`입니다. 감지된 방송을 직접 종료하면 같은 방송은 즉시 재시작하지 않으며 방송이 끝나거나 자동 감지를 다시 켜면 재개할 수 있습니다.

전역 단축키 또는 **마커**로 순간을 기록합니다. 기본값은 설치 버전 `Ctrl+Shift+F8`, 개발 모드 `Ctrl+Alt+F8`입니다. **설정 → 일반 → 타임라인 기록 단축키**에서 입력칸을 누르고 원하는 조합이나 F1~F24를 직접 누릅니다. 등록·저장에 실패하면 이전 키를 유지합니다.

동접 그래프는 플랫폼이 제공한 시청자 수를 합계·플랫폼별로 보여줍니다. 비공개·조회 불가 구간은 0명으로 추정하지 않고 그래프를 끊어 표시합니다. 마커는 창 크기에 맞춘 페이지로 조회합니다.

자동 하이라이트는 **최근 10초에 채팅 15개·참여자 5명 이상**, **앞선 60초 기준의 2.5배 이상**일 때 생성하며 45초간 중복 감지를 억제합니다. 반응 15초 전을 클립 시작 후보로 제안합니다. 로컬 통계로 찾는 편집 후보이며 영상·음성 녹화나 외부 AI 판정은 수행하지 않습니다.

</details>

## 채팅 기록과 날짜 선택

**방송 타임라인 → 채팅·후원**에서 방송·플랫폼·본문·닉네임으로 찾습니다. 기본은 전체 방송·전체 날짜이며 아래로 스크롤하면 이전 기록을 이어 읽습니다.

보관된 날짜를 정리하려면:

1. **날짜·용량 관리**를 열고 일·주·월 단위를 선택합니다.
2. 삭제할 날짜를 고르고 선택 용량을 확인합니다.
3. **선택 날짜 삭제**를 눌러 확인합니다. 기록 중인 날짜는 보호됩니다.

<details>
<summary>검색·날짜 선택·삭제 규칙</summary>

**방송 타임라인 → 채팅·후원**은 기본적으로 **전체 방송·전체 날짜**를 보여줍니다. 방송, 치지직·YouTube·트위치 또는 모든 플랫폼, 채팅/후원, 본문·닉네임·참여자 조건으로 조회합니다. 방송을 지정하면 경과 분 필터도 사용할 수 있습니다. 원문의 로컬 날짜·시각을 표시하며, 목록 안에서 아래로 스크롤하면 이전 기록을 이어서 읽습니다. 필요한 구간만 조회하고 화면 주변의 행만 표시합니다. 검색 조건이 바뀌면 목록의 처음부터 조회하며, 실시간 새 기록은 목록 맨 위에서 갱신됩니다. 글자 크기를 바꿔도 읽던 행을 유지합니다.

**날짜·용량 관리**에서 다음 순서로 관리합니다.

1. **일별 / 주별 / 월별**로 전환합니다. 주별은 월요일 기준입니다.
2. 여러 항목 클릭, Shift 범위 선택, 시작/종료 날짜 입력, **전체 선택**을 사용합니다. 주·월 선택은 그 안에 기록이 있는 날짜를 선택하며 줌 변경 후에도 실제 날짜 선택은 유지됩니다.
3. 선택 용량을 확인합니다. 참여자·동접을 포함한 암호화 원본 파일의 실제 길이이며 공유 통계·날짜 색인은 제외합니다. 파일시스템 할당 단위의 사용량과는 다릅니다.
4. **선택 날짜 삭제**를 누르고 날짜·용량을 확인합니다. 기록 중인 방송의 날짜는 보호하고 다른 날짜와 마커는 유지하며 통계를 다시 계산합니다.

여러 날짜를 담은 이전 파일은 선택 범위에서 한 번만 합산하고 공유 용량을 표시합니다. 공유 파일 정리와 필요한 참여자 프로필 보존 때문에 실제 확보 용량은 미리보기와 다를 수 있습니다. 삭제 도중 앱이 종료되어도 다음 실행에서 정리를 완료합니다. 방송 횟수를 기준으로 원문을 자동 삭제하지 않습니다.

</details>

## 채팅 분석과 내보내기

**분석·AI 데이터**에서 채팅량·반응·자주 나온 표현과 참여자 통계를 봅니다.

| 내보내기 | 용도 |
| --- | --- |
| **기록 내보내기 / JSON** | 방송 제목·시각·마커를 Markdown 또는 JSON으로 저장 |
| **분석 데이터 내보내기** | 채팅·후원·동접과 통계를 JSONL로 저장 |

기본 분석 내보내기는 닉네임을 가명으로 바꿉니다. 본문에 적힌 개인정보는 유지되며 내보낸 파일은 암호화되지 않습니다.

<details>
<summary>내보내는 정보와 화자 식별 방식</summary>

**분석·AI 데이터**에서 분 단위 채팅량, 문구 기반 반응, 자주 나온 표현과 참여자 통계를 확인합니다. 분석용 화자 키는 이 설치의 같은 플랫폼 계정을 방송 간 구분·연결하며 플랫폼이 다른 계정을 닉네임으로 합치지 않습니다. 구독·역할·배지는 플랫폼이 전달한 정보만 사용합니다.

| 내보내기 | 포함 내용 |
| --- | --- |
| 상단 **기록 내보내기 / JSON** | 선택 방송의 제목·시각·마커·하이라이트 근거를 Markdown/JSON으로 저장합니다. |
| **분석 데이터 내보내기** | 시점·참여자·원문 채팅·후원·동접·마커·로컬 통계를 JSONL로 저장합니다. |

기본 JSONL은 공개 계정·원문 메시지 ID를 제외하고 닉네임을 가명으로 바꾸며 분석용 화자 키를 유지합니다. **공개 닉네임·플랫폼 ID 포함**을 선택하면 공개 식별 정보를 넣습니다. 채팅 본문·마커 메모·반응 예시는 원문이므로 그 안의 개인정보를 자동 제거하지 않습니다. 내보낸 파일은 암호화되지 않은 일반 파일입니다.

</details>

## 시청자 추첨

1. **시청자 추첨**에서 아무 채팅 또는 참여 키워드로 모집합니다.
2. 필요하면 구독자·멤버십 조건과 이전 당첨자 제외를 설정합니다.
3. 모집 중이나 종료 후 추첨합니다. 전체 대상 중 한 명을 뽑고 결과를 보여줍니다.

플랫폼별 계정당 한 번 참여합니다. 새 모집을 시작하면 참여자와 당첨 기록을 초기화합니다.

<details>
<summary>추첨 애니메이션·대상과 인원 제한</summary>

아무 채팅 또는 키워드(기본 `!참여`)로 모집합니다. 치지직·트위치 구독자 및 YouTube 멤버십 전용, 이전 당첨자 제외와 자동 종료 타이머를 설정할 수 있습니다. 트위치는 Subscriber 또는 Founder 배지를 기준으로 판별합니다.

플랫폼별 계정당 한 번 참여합니다. 모집 중이거나 종료 후 추첨하며 전체 대상에서 암호학적 난수로 한 명을 선택합니다. 추첨 시점의 대상 수만큼 칸을 가진 원형 회전판에 이름을 같은 간격으로 한 번씩 배치합니다. 이름이 위에서 아래로 반복 회전하며 3초 동안 감속한 뒤 당첨자 칸에서 멈춥니다. 최근 목록의 100명 표시 제한과 관계없이 전체 대상을 배치하며, 추첨 중 추가 참여나 이름 변경은 다음 추첨에 반영됩니다. 탭·창을 이동해도 같은 명단과 추첨 시각을 이어가며, 동작 줄이기 설정에서는 바로 당첨자를 표시합니다. 중복 실행은 잠그고 탭 이동·재실행 후 결과를 유지합니다. 새 모집은 참여자와 당첨 기록을 초기화합니다.

최근 100명을 표시하지만 추첨 대상은 전체 참여자입니다. 기존 10,000명 모집 제한은 제거했습니다.

</details>

## 숫자 투표

1. 질문과 **2~4개 선택지**를 입력합니다. **추가** 또는 Enter로 선택지를 넣습니다.
2. 참여할 플랫폼을 선택하고 투표를 시작합니다. 기본 참여 명령은 `!투표1`입니다.
3. 실시간 결과를 보다가 **투표 종료**를 누릅니다. 종료 결과는 룰렛으로 가져올 수 있습니다.

YouTube에서는 채팅 명령 대신 기본 실시간 투표도 선택할 수 있습니다. **자동 종료 타이머**를 켜면 분·초로 1초~24시간을 지정합니다.

<details>
<summary>명령·표 변경·YouTube 투표·타이머 규칙</summary>

질문과 **2~4개 선택지**를 입력합니다. **추가** 또는 Enter로 추가하면 입력칸이 비워지고 커서가 유지됩니다. 한글 조합 중 Enter는 추가하지 않습니다. 항목 수정·삭제를 지원하며 처음 문구는 입력값이 아닌 안내입니다.

기본은 `!투표1` 또는 `!투표 1`이며 뒤에 일반 채팅을 이어 쓸 수 있습니다. 접두어는 12자 이하로 바꾸거나 비워 `1`처럼 번호만 정확히 입력받을 수 있습니다. 현재 참여 안내를 복사해 규칙을 설명합니다.

플랫폼별 계정당 한 표를 유지합니다. 새 유효 명령은 이전 선택에서 마지막 선택으로 표를 옮깁니다. 플랫폼 간 동일인 여부는 확인하지 않습니다. 기존 저장 투표는 원래 번호·첫 표 규칙을 유지합니다.

YouTube 채팅 명령 또는 기본 실시간 투표를 선택합니다. 기본 투표를 사용하면 해당 투표의 YouTube 채팅 명령을 집계하지 않아 두 방식의 중복을 방지합니다.

**자동 종료 타이머**를 켜고 분·초를 입력하면 지정 시간이 지난 뒤 투표를 종료합니다. 기본은 꺼짐이며 1초~24시간을 설정할 수 있습니다. 진행 화면에는 남은 시간을 표시합니다. 탭을 닫거나 창을 이동해도 공용 백엔드에서 타이머가 유지되고, 앱을 재시작해도 원래 종료 시각을 사용합니다. YouTube 기본 투표 종료가 실패하면 안내 후 다시 시도합니다.

시작하면 합계·비율·명령·경과 시간을 보여주는 방송용 현황으로 전환됩니다. **결과 가리기**, **투표 설정**, **투표 종료**를 사용할 수 있습니다. 종료 후 결과와 멈춘 타이머를 유지하며 **새 투표**는 빈 작성 화면을 엽니다. 종료 결과를 룰렛으로 가져올 수 있습니다.

</details>

## 도네 투표

치지직 치즈·YouTube 슈퍼챗의 지원되는 신규 메시지를 집계합니다.

1. 질문·**2~4개 선택지**·명령·통화를 설정합니다.
2. **1인 1표** 또는 **금액 배수** 규칙을 고릅니다.
3. 시작 후 결과를 확인하고 종료합니다. 자동 종료 타이머도 사용할 수 있습니다.

다른 통화는 환산하지 않습니다. 일반 채팅·익명 후원·스티커·과거 메시지는 투표에서 제외합니다. Twitch Bits 후원 투표는 지원하지 않습니다.

<details>
<summary>금액 계산 예시·지원 통화·중복 제외</summary>

2~4개 선택지, 명령(기본 `!투표`), 통화, 금액 규칙을 설정합니다. **자동 종료 타이머**는 선택 사항이며 분·초로 1초~24시간을 지정합니다. 탭·창 이동과 앱 재시작 후에도 종료 시각을 유지합니다.

| 방식          | 동작                                                                                                |
| ------------- | --------------------------------------------------------------------------------------------------- |
| **1인 1표**   | 최소 금액 이상의 후원을 한 표로 집계합니다. 다시 유효하게 후원하면 해당 시청자의 선택이 변경됩니다. |
| **금액 배수** | 건마다 `금액 / 1표당 금액`을 내림한 표를 누적합니다. 나머지는 다음 후원에 이월하지 않습니다.        |

1,000 KRW당 한 표이면 2,500 KRW는 2표, 이후 별도의 500 KRW는 0표입니다. 치지직 치즈는 KRW입니다. 슈퍼챗은 선택한 통화(KRW·USD·JPY·EUR·GBP·CAD·AUD)와 같은 경우만 집계합니다. 다른 통화는 제외 건수를 표시하며 환산하지 않습니다.

계정을 식별할 수 있고 명령이 유효한 신규 후원만 집계합니다. 일반 채팅·익명 후원·스티커·과거 메시지는 제외합니다. 중복 후원 ID는 재집계하지 않으며 저장 결과 복원 후에도 유지합니다.

방송용 현황과 룰렛 가져오기를 제공합니다. 기존 이벤트 50,000개 제한은 제거했으며 선택지당 10억 표의 계산 한도는 유지합니다.

</details>

## 가중치 룰렛

1. **2~12개 항목**과 가중치를 입력하거나 종료된 투표 결과를 가져옵니다.
2. **방송용 룰렛 보기 → 돌려!**를 누릅니다.
3. 선택된 항목에서 멈추는 결과를 확인합니다.

칸의 넓이와 실제 당첨 확률이 같습니다. 가중치 0인 항목은 당첨되지 않으며 회전 중에는 항목을 수정할 수 없습니다.

<details>
<summary>가중치 범위·회전·저장 규칙</summary>

서로 다른 이름의 항목 **2~12개**, 0~10억의 정수 가중치를 입력하거나 종료된 투표의 플랫폼 합산 결과를 가져옵니다. 0인 항목은 당첨되지 않으며 총합은 양수여야 합니다.

**방송용 룰렛 보기 → 돌려!**를 누릅니다. Node 엔진이 암호학적 난수로 가중치 구간을 선택합니다. 칸의 넓이·표시 확률·실제 추첨 확률이 같고 선택한 칸에 포인터가 멈추도록 회전합니다.

회전 시간은 매번 4~7초 사이에서 무작위로 정해지며, 시간 설정 항목은 표시하지 않습니다. 동작 줄이기 설정에서는 즉시 결과를 표시합니다.

회전 중 항목 수정·가져오기를 잠급니다. 탭을 바꾸어도 회전·결과를 유지합니다. 제목·항목·가중치는 로컬에 저장하고 설정 → 정보·데이터에서 확인 후 초기화합니다.

</details>

## AI 연결과 기능별 분석

AI 분석은 선택 사항입니다.

1. **설정 → AI 연결 → +**에서 AI를 추가하고 로그인 또는 API 키 연결을 합니다.
2. 모델을 조회한 뒤 **기능별 AI**에서 분석에 사용할 모델을 지정합니다. 선택하면 자동 저장합니다.
3. **방송 타임라인 → AI 분석**에서 기능·기록 범위·전송량을 확인하고 실행합니다.

선택한 기록은 지정된 CLI/API에 전달하며 API 요금이 발생할 수 있습니다. 가명 처리해도 본문 속 개인정보는 남습니다. [AI 가이드](ai-integrations.ko.md)에서 연결·그룹 설정·중지를 안내합니다.

<details>
<summary>기능별 설정과 계정·결과 관리</summary>

1. **설정 → AI 연결 → +**에서 사용할 AI를 추가합니다. 필요한 연결 모듈을 자동으로 내려받으며 CLI 실행 파일은 **다운로드·설치** 또는 **설치 관리 → 설치 찾기**로 준비합니다.
2. **CLI/API**를 선택해 로그인하거나 API 키를 저장합니다. CLI 인증 후 **모델 조회하고 계속**, API 연결 창에서는 **저장하고 연결 확인**으로 실제 모델 목록을 가져옵니다. 연결 화면의 **연결 저장**으로 기본 모델을 저장합니다.
3. **기능별 AI**에서 전체 기본값이나 그룹 기본값을 지정합니다. 채팅 분석의 자유 분석·질문 정리·반응 분석, 방송 정리의 방송 요약·하이라이트, 후원 분석의 후원 요약을 지원합니다. 선택 상자에서 AI·모델·추론 수준을 바꾸면 자동 저장합니다. **그룹 따르기**를 끈 기능만 개별 설정을 사용하며 **개별 기능 → 그룹 → 전체 기본값** 순서로 적용합니다. **AI 사용 안 함**으로 해당 범위의 분석을 끌 수 있습니다.
4. **방송 타임라인 → AI 분석**에서 기능과 방송·플랫폼·날짜·경과 시간 범위를 선택합니다. 적용되는 AI·모델·추론 수준과 전송 건수·전체 건수·샘플링 여부를 확인한 뒤 직접 실행합니다. AI가 지정되지 않았거나 연결을 사용할 수 없으면 **AI 지정하기**로 해당 기능 설정을 엽니다.
5. 결과의 사용량·제공되는 CLI 한도·API 추정 요금을 확인합니다. 진행 중 요청은 중지할 수 있고 저장된 결과는 다시 열거나 삭제할 수 있습니다.

Codex·Claude·Grok·Kimi는 앱 전용 로그인 프로필을 사용합니다. Antigravity는 **PC 로그인 공유**를 직접 켜면 PC의 공용 로그인 세션을 사용합니다. 로그인된 CLI는 **로그인 완료**로 표시하므로 계정을 바꿀 때 먼저 로그아웃합니다. API 키는 **API 키 관리**에서 변경합니다. CLI 구독과 API 요금은 별도입니다.

기본 분석은 닉네임을 가명으로 바꾸고 공개 계정 ID를 제외하지만 채팅 본문에 적힌 개인정보는 유지합니다. 선택한 기록은 실행할 때 지정된 CLI/API에 전달합니다. 자동 로컬 하이라이트와 별도로 제공되는 선택적 분석입니다. 자세한 인증·설정·전송 동작은 [AI 연결 가이드](ai-integrations.ko.md), 원본 형식은 [기록 형식](timeline-data.ko.md)을 참고하세요.

</details>

## 탭과 창 배치

탭을 좌우로 끌어 순서를 바꾸거나, 다른 창의 탭 영역에 놓아 옮깁니다. **+**로 도구를 추가할 수 있습니다.

탭을 우클릭하면:

| 메뉴 | 동작 |
| --- | --- |
| **새 창에서 보기** | 현재 입력과 화면을 별도 창에 복제 |
| **새 탭에서 보기** | 현재 입력과 화면을 같은 창의 새 탭에 복제 |
| **닫기** | 해당 탭의 화면과 임시 입력 해제 |
| **모두 닫기** | 현재 창의 도구 탭 닫기 |
| **비활성 탭 숨김** | 아직 열지 않은 도구 표시 숨기기 |
| **탑바 숨김** | 상단에 마우스를 올렸을 때만 탑바 표시 |

기록·채팅 수집·진행 중 투표와 모집은 모든 창이 공유하며 탭을 닫아도 계속됩니다. 검색·입력·룰렛은 탭별로 관리합니다. 탭 배치와 창 위치는 재시작 후 복원됩니다.

<details>
<summary>드래그·비활성 표시·복원과 화면 보기</summary>

방송 타임라인·시청자 추첨·숫자 투표·도네 투표·룰렛 탭을 좌우로 끌어 순서를 바꿉니다. 해당 창에 활성 도구 탭이 여러 개일 때 하나를 상단 탭 영역 밖으로 끌면 별도 창이 열립니다. 해당 창의 마지막 활성 도구 탭을 끌면 새 창을 만들지 않고 기존 창 자체를 이동합니다. 비활성 표시·홈·설정은 활성 도구 탭 개수에 포함하지 않습니다. 전체 앱 창이 두 개 이상이면 탭 드래그로 움직이는 창만 반투명해지고, 나머지 창은 불투명하게 유지합니다. 창이 하나뿐이면 이동 중에도 불투명하게 유지합니다. 어느 창이든 다른 창의 탭 영역에 놓아 탭을 옮길 수 있습니다. 드래그 종료·취소 후 투명도는 원래대로 돌아옵니다. 모든 창에 홈, 도구 추가와 **설정**이 있으며 설정 탭은 고정됩니다. 이동 중 Esc를 누르면 원래 배치와 위치로 돌아갑니다. 로고는 클릭하면 홈을 열고, 끌면 전체 창을 이동합니다.

탭을 우클릭하면 **새 창에서 보기 / 새 탭에서 보기 / 닫기 / 모두 닫기 / 비활성 탭 숨김 / 탑바 숨김**을 선택할 수 있습니다. **모두 닫기**는 현재 창의 도구 탭을 닫고 비활성 기본 자리로 돌리며, 다른 창의 탭과 설정은 유지합니다. 새 창·새 탭에서 보기는 원래 탭을 유지하면서 현재 입력과 화면을 복제합니다. 같은 종류의 탭을 여러 개 열 수 있고 입력값·룰렛 항목과 회전 상태는 탭별로 관리합니다. **+** 버튼에서도 원하는 도구의 새 탭을 추가할 수 있습니다.

같은 창에 열린 동일 종류의 탭이 여러 개면 이름에 **1, 2…**를 붙입니다. 닫거나 다른 창으로 옮겨 하나만 남으면 번호를 자동으로 없앱니다.

모든 창은 각 도구 종류의 기본 자리를 갖습니다. 새 창에서 아직 열지 않은 도구나 활성 탭을 닫아 없어진 도구는 반투명한 **+** 비활성 표시로 남습니다. 다른 창에 탭을 옮겨도 원래 창에 활성 탭이 남아 있으면 해당 도구의 기본 자리를 유지합니다. 비활성 표시는 화면·입력·타이머를 메모리에 올리지 않습니다. 클릭하거나 **+ → 비활성 탭 열기**에서 활성화합니다.

활성 탭은 다른 탭을 선택해도 화면과 데이터가 유지됩니다. **닫기** 또는 **모두 닫기**를 누르면 해당 화면·타이머·임시 입력 상태를 해제합니다. 같은 종류의 다른 활성 탭이 남아 있으면 그 탭을 유지하고, 모두 닫히면 비활성 기본 자리로 돌아갑니다. 해당 창의 마지막 활성 탭을 다른 창에 합치면 탭 데이터가 이동하고 원래 창은 닫힙니다. 기본 창도 같은 방식으로 닫히며 남은 창이 기본 창의 역할을 이어받습니다. 닫힌 원래 창은 재시작 후 다시 생성하지 않습니다.

**비활성 탭 숨김**은 반투명한 기본 표시만 숨기는 옵션이며 각 창에 따로 저장합니다. 숨겨도 기본 자리 정보는 유지됩니다. 새 창을 만들 때 원래 창의 옵션을 복사하며, 이후 변경은 다른 창에 영향을 주지 않습니다.

**탑바 숨김**을 켜면 상단 탑바 공간까지 본문을 넓힙니다. 상단 영역에 마우스를 올리면 탑바가 슬라이드되어 나타나고, 벗어나면 다시 숨습니다. 메뉴 사용과 탭 드래그 중에는 펼친 상태를 유지합니다. 표시된 탭을 우클릭해 옵션을 끄면 항상 표시합니다. 창별로 저장하고 새 창에 복사하며 재시작 후에도 유지합니다.

각 창의 탭 구성·순서·닫힌 상태, 활성 탭, 숨김 옵션과 창의 위치·크기는 자동 저장되며 재시작 후 복원됩니다. 보조 창 전체를 닫으면 그 창의 탭을 메인 창으로 돌려보냅니다. 방송·채팅 수집·플랫폼 연동과 진행 중인 투표·모집은 모든 창이 공유하며 탭을 닫아도 계속됩니다. 기록과 탭별로 저장한 룰렛 항목은 삭제하지 않습니다.

## 창·트레이·데이터

**설정 → 일반 → 화면 테마 → 글자 크기**에서 95~150%로 조절합니다. 슬라이더를 놓으면 모든 창에 적용하고, 재시작 후에도 유지합니다.

- 보조 창을 닫으면 탭을 기본 창으로 돌려보냅니다.
- 트레이가 켜져 있으면 기본 창을 닫아도 수집은 계속됩니다. 완전 종료는 트레이 메뉴에서 합니다.
- 트레이가 꺼져 있고 기본 창만 남아 있으면 닫을 때 저장하고 종료합니다.

기록 삭제는 **설정 → 정보·데이터**에서 확인 후 실행합니다. 먼저 기록·모집·투표를 종료하세요. 내보낸 파일과 별도 백업은 직접 관리합니다.

<details>
<summary>글자 크기·닫기·저장 파일과 삭제 범위</summary>

프레임 없는 헤더를 드래그해 이동하고 사용자 지정 버튼으로 최소화·최대화·종료합니다. 테마를 유지하고 Windows 동작 줄이기 설정을 존중합니다. **설정 → 일반 → 화면 테마 → 글자 크기**에서 슬라이드바로 95~150%를 5% 단위로 조절합니다. 기본값은 100%이며, 기본값 복원 버튼으로 돌아갈 수 있습니다. 슬라이더를 끌 때는 수치만 미리 표시하고 놓으면 적용합니다. 키보드 방향키·Home·End로도 조절할 수 있습니다. 모든 창에 적용하며 재시작 후에도 유지합니다. 최소 900 × 650에서도 전체 화면에 스크롤이 생기지 않으며 긴 목록은 패널 안에서 스크롤합니다. 글자가 커지면 여백과 내용 배치를 조정하며 방송용 현황·실행 버튼은 창 안에 유지합니다. AI 연결 목록은 한 페이지에 6개씩 표시하고 이전/다음 버튼으로 이동합니다. 긴 로그인 안내는 창 내부에서 스크롤하며 하단 동작 버튼은 계속 표시됩니다.

![150% 글자 크기 설정](assets/screenshots/text-size.png)

- **보조 창:** 창을 닫으면 그 창의 탭을 기본 창으로 돌려보냅니다.
- **트레이 켜짐:** 기본 창을 닫으면 숨겨지고 수집·타이머는 Electron main에서 계속됩니다. 완전 종료는 트레이 메뉴에서 실행합니다.
- **트레이 꺼짐:** 기본 창만 남아 있을 때 닫으면 기록을 저장하고 종료합니다. 보조 창이 열려 있으면 기본 창을 숨깁니다.
- **자동 시작:** 설치 EXE에서는 토글, MSIX에서는 Windows 시작 앱 설정을 사용합니다. 개발 모드는 Windows 자동 시작을 변경하지 않습니다.

`userData`(일반적으로 `%APPDATA%/streamer-assist`)에 `records.enc`로 기록, `accounts.enc`로 YouTube·트위치 토큰을 Windows DPAPI 암호화 저장합니다. 일반 설정·룰렛 항목은 로컬 앱 설정이며 Markdown/JSON/JSONL 내보내기는 일반 파일입니다.

방송 제목·마커·참여 결과는 `records.enc`, 원문 채팅·후원·프로필·동접은 `timeline-data/<방송 UUID>/`에 저장합니다. 최근 100회 보관 제한을 제거했습니다. 반응 감지는 메시지마다 전체 버퍼를 순회하지 않는 10초·70초 증분 집계를 사용하며 원문 보관 기간과는 별개입니다. 표시·통계 색인에는 제한이 있으며 원문은 삭제 전까지 유지합니다. 기존 평문 메타데이터는 암호화 저장 후 마이그레이션합니다.

**설정 → 정보·데이터**에 개인정보처리방침·체험 안내·확인 후 기록 삭제가 있습니다. 기록·모집·투표를 먼저 종료합니다. 삭제는 암호화 복구본도 지우고 연결 계정·설정은 유지합니다. YouTube는 별도로 연결 해제하고 필요 시 Google 연결된 앱 설정에서 권한을 철회합니다.

## 플랫폼과 제한

- **치지직:** 비공식 공개 채팅 읽기 방식입니다. 로그인 제한 방송은 지원하지 않습니다.
- **YouTube:** 방송 채널 소유자의 승인과 활성 방송이 필요합니다.
- **Twitch:** 채팅 하이라이트·숫자 투표·구독자/Founder 추첨을 지원합니다. 기본 투표·Bits 후원 투표는 지원하지 않습니다.

자동 검사는 모의 응답을 사용합니다. 실제 로그인·방송 수신·유료 후원 동작은 실환경에서 추가 검증해야 합니다.

<details>
<summary>수집·인증 프로토콜과 검증 범위</summary>

- 치지직은 비공식 공개 채팅 읽기 프로토콜입니다. 로그인 필수 방송은 지원하지 않으며 서비스 변경 시 연결이 중단될 수 있습니다. 채널 변경·끊김을 주기적으로 확인하고 임시 익명 읽기 인증 정보는 메모리에만 보관합니다.
- YouTube는 공식 API와 `pollingIntervalMillis`를 따릅니다. OAuth는 `youtube.force-ssl` 권한·PKCE·`127.0.0.1`의 임시 콜백을 사용하고 로그인 후 콜백을 닫습니다.
- 트위치는 공식 EventSub WebSocket과 `user:read:chat` 권한을 사용합니다. 재연결 중에도 중복 메시지를 제외하며 Shared Chat의 다른 채널 메시지는 집계하지 않습니다. Bits 메시지는 BITS 단위의 후원 기록으로 보관하지만 Bits 도네 투표와 트위치 기본 투표는 지원하지 않습니다.
- 숨김 치지직 메시지는 수집하지 않습니다. 제공된 과거 채팅은 원래 시각·과거 기록 표시와 함께 보관하고 실시간 급증 감지·투표에서는 제외합니다. 익명 치즈·유료 스티커를 기록에 보관해도 도네 투표로 집계하지는 않습니다.
- 자동 검증은 모의 응답·로컬 트위치 EventSub 소켓·격리 프로필을 사용합니다. 정식 배포 전 실제 YouTube·트위치 로그인·방송 채팅·기본 투표·유료 후원 수신을 방송 환경에서 추가 확인해야 합니다.
- CI 설치 검사가 Microsoft 인증을 의미하지 않습니다. [Store 설정](store-setup.md)을 참고하세요.

</details>


## 방송 종료 후 채팅 수집

**설정 → 방송 기록**에서 실시간 저장·실시간 원본 저장 후 분석·실시간 기능만 사용 후 다시보기 수집을 선택합니다. 다음 방송부터 적용합니다. 종료 후 **타임라인 → 다시보기 수집**에서 연결된 영상을 찾거나 URL을 하나씩 추가합니다. 수집 중지·재시도, 선택적인 통계·하이라이트 계산을 지원합니다. 필요하면 영상 시작 시각을 조정합니다. 도구는 선택 다운로드하며 영상 파일을 내려받지 않습니다. 삭제·비공개·미제공 채팅은 복구할 수 없습니다. [원본 형식·한계](timeline-data.ko.md)를 참고하세요.
