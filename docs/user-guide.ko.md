# 사용 가이드

[English](user-guide.md) · **한국어** · [README로 돌아가기](../README.ko.md)

현재 앱 화면 언어는 한국어입니다.

## 연결 없이 체험하기

`npm run dev`로 실행합니다. **방송 타임라인**에서 기록을 시작하고 **설정 → 일반 → 테스트 채팅**을 켭니다.

모의 이벤트에서 하이라이트·추첨 참여자·후원이 생성됩니다. 테스트 모드에서는 테스트 플랫폼이 나타나며 실제 투표 게시나 후원 결제를 하지 않습니다. 실제 플랫폼을 사용하기 전에 테스트 채팅을 끄세요. 룰렛은 독립적으로 사용할 수 있습니다.

## 타임라인과 하이라이트

1. 제목을 입력하고 **방송 기록 시작**을 누릅니다. 이미 방송 중이라면 먼저 경과 초를 입력합니다. 30분은 `1800`입니다.
2. 전역 단축키 또는 메모 입력 후 **마커**로 기록합니다. 기본값은 설치 버전 `Ctrl+Shift+F8`, 개발 모드 `Ctrl+Alt+F8`입니다.
3. **설정 → 일반 → 타임라인 기록 단축키**에서 입력칸을 누른 뒤 원하는 키를 직접 누릅니다. Ctrl/Alt/Shift/Win 조합 또는 F1~F24를 사용합니다. 충돌·저장 실패 시 기존 단축키를 유지합니다.
4. 종료 후 Markdown/JSON으로 내보냅니다. 방송 선택 메뉴에서 이전 기록을 확인합니다.

시간은 로컬 기록 시작과 입력한 경과 초를 기준으로 계산하며 플랫폼과 자동 동기화하지 않습니다. 홈에서 현재 기록·마커 및 하이라이트 수·최근 두 순간을 보고 타임라인 버튼으로 기록 화면을 엽니다.

자동 하이라이트는 **최근 10초에 채팅 15개·참여자 5명 이상**, **앞선 60초 평균의 2.5배 이상**일 때 생성합니다. 웃음·감탄 예시를 표시하고 45초간 중복 감지를 억제하며 반응 15초 전을 클립 시작 후보로 제안합니다.

통계로 찾는 편집 후보입니다. 영상·음성 녹화와 분석, 외부 AI 호출, 실제 재미 판정은 제공하지 않습니다.

## 플랫폼 연결

**설정 → 플랫폼 연결**에서 설정합니다.

| 플랫폼  | 연결 방법                                                                        | 참여 기능                                                                                 |
| ------- | -------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 치지직  | 공개 채널·라이브 주소 또는 채널 ID. 로그인과 개발자 앱 등록이 필요하지 않습니다. | 읽기 전용 채팅, 명령 투표, 추첨과 지원되는 치즈 후원. 참여 안내는 복사해 직접 공지합니다. |
| YouTube | 방송 채널 소유자로 브라우저 로그인 후 진행 중인 방송 채팅을 자동 탐색합니다.     | 채팅 명령, 기본 실시간 투표, 추첨과 지원되는 슈퍼챗 메시지.                               |

직접 빌드하는 YouTube 앱은 [개발자 OAuth 설정](development.ko.md#youtube-oauth)이 필요합니다. 사용자는 브라우저에서 권한을 부여하며 토큰을 직접 입력하지 않습니다. 방송이 없으면 대기하고 **방송 채팅 다시 찾기**로 재탐색합니다.

연결된 플랫폼만 참여 버튼으로 나타납니다. 시작 전에 켜거나 끄며 선택한 플랫폼에 실시간 채팅이 준비되어 있어야 합니다. 시작 후 플랫폼·명령 설정은 고정됩니다. 선택한 플랫폼이 없으면 시작할 수 없습니다.

## 숫자 투표

질문과 **2~4개 선택지**를 입력합니다. **추가** 또는 Enter로 추가하면 입력칸이 비워지고 커서가 유지됩니다. 한글 조합 중 Enter는 추가하지 않습니다. 항목 수정·삭제를 지원하며 처음 문구는 입력값이 아닌 안내입니다.

기본은 `!투표1` 또는 `!투표 1`이며 뒤에 일반 채팅을 이어 쓸 수 있습니다. 접두어는 12자 이하로 바꾸거나 비워 `1`처럼 번호만 정확히 입력받을 수 있습니다. 현재 참여 안내를 복사해 규칙을 설명합니다.

플랫폼별 계정당 한 표를 유지합니다. 새 유효 명령은 이전 선택에서 마지막 선택으로 표를 옮깁니다. 플랫폼 간 동일인 여부는 확인하지 않습니다. 기존 저장 투표는 원래 번호·첫 표 규칙을 유지합니다.

YouTube 채팅 명령 또는 기본 실시간 투표를 선택합니다. 기본 투표를 사용하면 해당 투표의 YouTube 채팅 명령을 집계하지 않아 두 방식의 중복을 방지합니다.

시작하면 합계·비율·명령·경과 시간을 보여주는 방송용 현황으로 전환됩니다. **결과 가리기**, **투표 설정**, **투표 종료**를 사용할 수 있습니다. 종료 후 결과와 멈춘 타이머를 유지하며 **새 투표**는 빈 작성 화면을 엽니다. 종료 결과를 룰렛으로 가져올 수 있습니다.

## 시청자 추첨

아무 채팅 또는 키워드(기본 `!참여`)로 모집합니다. 치지직 구독자·YouTube 멤버십 전용, 이전 당첨자 제외와 자동 종료 타이머를 설정할 수 있습니다.

플랫폼별 계정당 한 번 참여합니다. 모집 중이거나 종료 후 추첨하며 전체 대상에서 암호학적 난수로 한 명을 선택합니다. 3초간 중복 실행을 잠그고 애니메이션으로 당첨자를 공개합니다. 탭 이동·재실행 후 결과를 유지합니다. 새 모집은 참여자와 당첨 기록을 초기화합니다.

최근 100명을 표시하지만 추첨 대상은 전체 참여자입니다. 10,000명에 도달하면 안내와 함께 모집을 종료합니다.

## 도네 투표

2~4개 선택지, 명령(기본 `!투표`), 통화, 금액 규칙과 선택적인 타이머를 설정합니다.

| 방식          | 동작                                                                                                |
| ------------- | --------------------------------------------------------------------------------------------------- |
| **1인 1표**   | 최소 금액 이상의 후원을 한 표로 집계합니다. 다시 유효하게 후원하면 해당 시청자의 선택이 변경됩니다. |
| **금액 배수** | 건마다 `금액 / 1표당 금액`을 내림한 표를 누적합니다. 나머지는 다음 후원에 이월하지 않습니다.        |

1,000 KRW당 한 표이면 2,500 KRW는 2표, 이후 별도의 500 KRW는 0표입니다. 치지직 치즈는 KRW입니다. 슈퍼챗은 선택한 통화(KRW·USD·JPY·EUR·GBP·CAD·AUD)와 같은 경우만 집계합니다. 다른 통화는 제외 건수를 표시하며 환산하지 않습니다.

계정을 식별할 수 있고 명령이 유효한 신규 후원만 집계합니다. 일반 채팅·익명 후원·스티커·과거 메시지는 제외합니다. 중복 후원 ID는 재집계하지 않으며 저장 결과 복원 후에도 유지합니다.

방송용 현황과 룰렛 가져오기를 제공합니다. 이벤트 50,000개 또는 선택지당 10억 표에 도달하면 종료합니다.

## 가중치 룰렛

서로 다른 이름의 항목 **2~12개**, 0~10억의 정수 가중치를 입력하거나 종료된 투표의 플랫폼 합산 결과를 가져옵니다. 0인 항목은 당첨되지 않으며 총합은 양수여야 합니다.

**방송용 룰렛 보기 → 돌려!**를 누릅니다. Node 엔진이 암호학적 난수로 가중치 구간을 선택합니다. 칸의 넓이·표시 확률·실제 추첨 확률이 같고 선택한 칸에 포인터가 멈추도록 회전합니다.

회전 중 항목 수정·가져오기를 잠급니다. 탭을 바꾸어도 회전·결과를 유지합니다. 제목·항목·가중치는 로컬에 저장하고 설정 → 정보·데이터에서 확인 후 초기화합니다.

## 창·트레이·데이터

프레임 없는 헤더를 드래그해 이동하고 사용자 지정 버튼으로 최소화·최대화·종료합니다. 테마를 유지하고 Windows 동작 줄이기 설정을 존중합니다. 최소 900 × 650에서도 전체 화면에 스크롤이 생기지 않으며 긴 목록은 패널 안에서 스크롤합니다.

- **트레이 켜짐:** 창을 닫으면 숨겨지고 수집·타이머는 Electron main에서 계속됩니다. 완전 종료는 트레이 메뉴에서 실행합니다.
- **트레이 꺼짐:** 닫을 때 기록을 저장하고 종료합니다.
- **자동 시작:** 설치 EXE에서는 토글, MSIX에서는 Windows 시작 앱 설정을 사용합니다. 개발 모드는 Windows 자동 시작을 변경하지 않습니다.

`userData`(일반적으로 `%APPDATA%/streamer-assist`)에 `records.enc`로 기록, `accounts.enc`로 YouTube 토큰을 Windows DPAPI 암호화 저장합니다. 일반 설정·룰렛 항목은 로컬 앱 설정이며 Markdown/JSON 내보내기는 일반 파일입니다.

현재 방송과 최근 100회 방송을 유지합니다. 마커·일부 반응 예시·참여 결과·중복 방지 식별자를 저장하며 전체 로그는 저장하지 않습니다. 메모리 분석 버퍼는 70초/최대 10,000개입니다. 기존 평문 기록은 암호화 저장에 성공한 뒤 마이그레이션하고 암호화 복구본을 남깁니다.

**설정 → 정보·데이터**에 개인정보처리방침·체험 안내·확인 후 기록 삭제가 있습니다. 기록·모집·투표를 먼저 종료합니다. 삭제는 암호화 복구본도 지우고 연결 계정·설정은 유지합니다. YouTube는 별도로 연결 해제하고 필요 시 Google 연결된 앱 설정에서 권한을 철회합니다.

## 플랫폼과 제한

- 치지직은 비공식 공개 채팅 읽기 프로토콜입니다. 로그인 필수 방송은 지원하지 않으며 서비스 변경 시 연결이 중단될 수 있습니다. 채널 변경·끊김을 주기적으로 확인하고 임시 익명 읽기 인증 정보는 메모리에만 보관합니다.
- YouTube는 공식 API와 `pollingIntervalMillis`를 따릅니다. OAuth는 `youtube.force-ssl` 권한·PKCE·`127.0.0.1`의 임시 콜백을 사용하고 로그인 후 콜백을 닫습니다.
- 숨김 치지직 메시지와 오래된 조회 채팅은 분석·투표에서 제외합니다.
- 자동 검증은 모의 응답과 격리 프로필을 사용합니다. 정식 배포 전 실제 YouTube 로그인·방송 채팅·기본 투표·유료 후원 수신을 방송 환경에서 추가 확인해야 합니다.
- CI 설치 검사가 Microsoft 인증을 의미하지 않습니다. [Store 설정](store-setup.md)을 참고하세요.
