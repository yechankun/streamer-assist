# Streamer Assist v0.4.4

## 한국어

- 당첨자 결과를 픽셀 캐릭터와 말풍선 대화로 표시하는 선택 옵션을 추가했습니다. 추첨 화면이나 결과 창의 얼굴 아이콘으로 켜고 끕니다. 기본값은 꺼짐이며, 선택은 다른 추첨 창과 공유하고 앱을 다시 실행해도 유지됩니다.
- 몸 5종과 헤어·상의·하의·모자·소품 각 15종을 부위별로 조합합니다. 모자와 소품을 생략하는 경우까지 모양 조합은 432만 가지입니다.
- 15개 기본색으로 구성한 숲·바다·벚꽃·보라·노을·겨울·흙빛·무채색의 8개 팔레트를 추가했습니다. 같은 부품에서도 다른 색 조합이 나오며 원래 아트의 색상도 사용합니다. 피부색과 명암은 유지합니다.
- 캐릭터 모양과 색은 추첨 결과마다 정해집니다. 채팅 추가, 표시 모드 전환, 다른 창에서 같은 결과를 볼 때도 유지되며 추첨 확률에는 영향을 주지 않습니다. 캐릭터를 만들기 위한 외부 요청은 없습니다.
- 포니테일이 얼굴을 가리던 위치와 비율을 수정하고, 모자·헤어밴드와의 배치를 확인했습니다.
- 당첨 직전 채팅은 회색 말풍선으로, 이후 채팅은 강조색 말풍선으로 이어집니다. 기존 당첨자 TTS를 그대로 사용할 수 있으며 표시 모드를 바꿔도 이전 메시지를 다시 읽지 않습니다.

앱 버전은 **0.4.4**, Microsoft Store MSIX 버전은 **1.4.4.0**입니다.

## English

- Add an optional pixel character and speech-bubble presentation for raffle winners. Toggle it with the face icon in the raffle or result view. It is off by default; the choice is shared across raffle windows and persists across restarts.
- Compose avatars from five bodies and fifteen hairstyles, tops, bottoms, hats and accessories per category. Including absent hats/accessories, there are 4.32 million shape combinations.
- Add fifteen base colors arranged into eight coordinated palettes: forest, coast, blossom, violet, sunset, winter, earth and monochrome. The same part can use different colors, with original artwork colors also retained. Skin and ordered shading are preserved.
- Keep appearance and colors stable for each draw across incoming chat, presentation toggles and windows. Cosmetic choices do not affect raffle probabilities and require no external generation service.
- Correct ponytail positioning and proportions, including its fit beneath hats and headbands.
- Show pre-draw chat in muted bubbles and subsequent messages in accent bubbles. Existing winner TTS remains available; changing presentation never replays old messages.

App version: **0.4.4**. Microsoft Store MSIX version: **1.4.4.0**.

*Screenshots use the app's actual character renderer with synthetic names and chat.*
