## 한국어

- 투표 중에는 각 선택지 옆에 실제 채팅·후원 명령어를 크게 표시합니다. YouTube 기본 투표의 최종 득표수가 도착하면 채팅 표와 합산해 순위를 표시합니다. 공동 순위, 집계 대기와 결과 비공개 상태를 구분합니다.
- 추첨 화면의 참여 안내와 복사 문구가 모집 종료, 플랫폼 선택, 채팅 연결 상태를 반영합니다. 명단 위에서 참여 조건과 표시 옵션을 조정할 수 있습니다.
- 미연결 홈에서는 방송 연결로 바로 이동합니다. 방송 전 타임라인에는 기록 시작과 감지 상태를 먼저 표시하고 제목과 경과 시간은 필요할 때 펼칩니다. 최근 방송도 다시 열 수 있습니다.
- AI 분석은 질문 작성과 결과 읽기를 구분하고 본문 글자와 읽기 영역을 키웠습니다. 분석 중에도 저장된 결과를 읽을 수 있고, 중지는 진행 중인 분석에 적용됩니다.
