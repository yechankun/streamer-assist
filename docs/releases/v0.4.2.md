# Streamer Assist v0.4.2

![당첨 효과 · Winner celebration](https://raw.githubusercontent.com/yechankun/streamer-assist/main/docs/assets/demos/winner-celebration.gif)

*테스트 채팅으로 촬영한 실제 앱 화면 · Actual app with generated test chat.*

## 한국어

- 시청자 추첨 당첨 결과에 폭죽과 흩날리는 색종이·리본 효과를 추가했습니다. 효과가 끝나도 당첨자와 채팅은 창을 닫을 때까지 표시합니다.
- 당첨 직전 마지막 채팅을 회색으로 바로 보여주고, 이후 같은 플랫폼의 같은 당첨 계정이 보내는 채팅을 강조색으로 이어 표시합니다. 별도 구분 제목이나 대기 안내 없이 한 흐름으로 읽습니다.
- 모집을 종료한 뒤에도 채팅 연결이 유지되면 당첨자의 새 메시지를 받습니다. 최근 50개의 새 메시지를 유지하고, 닫기·Esc로 결과 창을 닫으면 표시를 종료합니다. 표시용 메시지는 메모리에만 보관하며 앱 재시작 후 복원하지 않습니다.
- 밝은·어두운 테마, 긴 닉네임·채팅과 150% 글자 크기의 당첨 결과 화면을 지원합니다. 동작 줄이기 설정에서는 축하 효과를 생략합니다.
- Google 로그인 대기 시간을 10분으로 늘려 로그인·2단계 인증 도중 로컬 콜백이 먼저 종료되는 상황을 줄였습니다.
- 사용자 안내와 Google OAuth 검증 영상용 개발 도구·OBS 작업 규칙을 갱신했습니다. 촬영 도구와 영상은 앱 설치 프로그램에 포함하지 않습니다.

앱 버전은 **0.4.2**, Store MSIX 버전은 **1.4.2.0**입니다. 축하 효과에는 fireworks-js(MIT)와 canvas-confetti(ISC)를 사용하며 라이선스를 설치 파일에 포함합니다.

## English

- Celebrate raffle winners with fireworks and drifting confetti and ribbons. The winner and chat remain visible after the effects finish, until the result dialog is closed.
- Show the winner's last pre-draw chat immediately in gray, then append new messages from the same account on the same platform in the accent color. Read them as one stream without explanatory headings or waiting text.
- Continue receiving the winner's chat after recruitment ends while the connection remains active. Keep the latest 50 new messages; closing the dialog or pressing Escape stops the preview. Preview messages remain in memory only and are not restored after restarting the app.
- Support light/dark themes, long names/messages and 150% text size in the result dialog. Reduced motion skips celebration effects.
- Extend Google login waiting time to ten minutes, reducing expired local callbacks during sign-in and two-factor authentication.
- Update user guidance, OAuth verification recording tools and rules for preserving the existing OBS setup. Recording tools and videos are not included in app installers.

App version: **0.4.2**. Store MSIX version: **1.4.2.0**. Celebration effects use fireworks-js (MIT) and canvas-confetti (ISC), with their licenses included in the app.
