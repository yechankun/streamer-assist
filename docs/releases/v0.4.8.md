# Streamer Assist v0.4.8

## 한국어

- 추첨·숫자 투표·도네 투표의 진행 화면에 현재 참여 방법과 조건, 진행 상태, 경과 시간과 남은 시간을 표시합니다. 추첨하기·모집 종료·투표 종료 버튼을 명확하게 구분했습니다.
- 상단에 연결된 방송의 채널 이름·프로필 사진·방송 상태를 표시하고, 대표 플랫폼을 선택해 저장합니다. 선택한 연결이 끊기면 다른 연결을 표시하고 재연결 시 원래 선택을 복원합니다.
- **실시간 설정**에서 진행 중인 추첨의 제목·참여 키워드·구독자 조건·당첨자 제외·참여 플랫폼·타이머를 변경할 수 있습니다. 명단과 당첨 기록은 유지하고 현재 추첨 대상이 아닌 이름은 흐리게 표시합니다.
- 숫자·도네 투표의 질문·선택지·참여 명령·플랫폼·타이머와 도네 투표의 후원 금액·통화·표수 계산 방식을 진행 중에 수정할 수 있습니다. 기존 표는 유지하고 새 규칙은 적용 후 받은 메시지부터 사용합니다. 표가 없는 선택지는 삭제할 수 있고, 표를 받은 선택지는 이름을 수정할 수 있습니다.
- 타이머를 그대로 두면 원래 종료 시각을 유지하며 시간을 바꾸면 적용 시점부터 다시 계산합니다. 다른 창에서 먼저 수정한 설정을 덮어쓰지 않도록 보호합니다. YouTube 기본 투표의 질문·선택지는 플랫폼 API 제한으로 진행 중 수정할 수 없습니다.
- 프로필 이미지는 메모리에서만 임시 보관합니다. 개인정보처리방침이 갱신되어 기존 YouTube 연결은 새 안내에 재동의해야 합니다. 참여 플랫폼 변경 이후에도 YouTube 데이터 삭제·보관 기간 정리를 유지합니다.
- 사용 가이드와 실제 앱 화면을 갱신하고, 두 테마·900 × 650 창·글자 크기 150%에서 진행 화면과 설정 창을 검증했습니다.

앱 버전: **0.4.8** · Microsoft Store MSIX 버전: **1.4.8.0**.

## English

- Show current participation instructions, eligibility rules, status, elapsed time and remaining time on raffle, number-vote and donation-vote stages. Make draw, end recruitment and end vote actions clear.
- Display the connected broadcaster's channel name, profile image and live status. Save a representative-platform preference, fall back while disconnected and restore it on reconnection.
- Edit active raffle titles, entry keywords, subscriber and previous-winner filters, platforms and timers without resetting entrants or winner history. Dim entrants currently excluded by the filters.
- Edit running vote questions, choice labels, commands, platforms and timers, plus donation amounts, currencies and counting methods. Retain received votes; apply new rules to subsequently received messages. Delete only choices with no votes; rename choices that already have votes.
- Preserve an untouched timer's deadline, or start a changed duration from Apply. Protect against stale edits from another window. Running native YouTube polls retain their published questions and choices because the API does not support editing them.
- Cache profile images only in memory. The updated privacy notice requires existing YouTube connections to accept the new notice. Preserve YouTube deletion and retention cleanup after participation-platform changes.
- Update user guides and actual app captures. Verify both themes, a 900 × 650 window and 150% text for stages and live-settings dialogs.

App version: **0.4.8** · Microsoft Store MSIX version: **1.4.8.0**.
