# Streamer Assist v0.4.13

## 한국어

- 일부 치지직 채널에서 프로필 사진이 표시되지 않던 문제를 고쳤습니다.
- 시청자 추첨과 진행 중인 숫자·도네 투표 설정에는 연결된 플랫폼의 참여 버튼만 표시됩니다. 연결이 끊겼다가 돌아오면 기존 선택이 복원됩니다.
- 채팅 읽기를 켜면 시청자 이름을 누르거나 당첨자 창이 열린 뒤 약 0.8초 후에 화면에 표시된 직전 채팅을 한 번 읽습니다. 그사이에 들어온 새 채팅은 이어서 읽고, 창을 닫거나 음소거하면 대기 중인 읽기도 취소합니다.
- 추첨과 숫자 투표에서 연결을 기다리는 동안 반복되던 안내를 줄였습니다. 빈 시청자·당첨자 채팅창에는 첫 메시지가 오면 채팅이 표시됩니다.

앱 **0.4.13** · Microsoft Store **1.4.13.0**

## English

- Fixed missing profile pictures for some CHZZK channels.
- Viewer raffles and live number and donation vote settings show participation buttons for connected platforms. When a platform reconnects, its previous selection returns.
- With chat speech enabled, opening a viewer or winner dialog starts a short pause of about 0.8 seconds. The reader speaks the last displayed message once and then reads incoming chat. Closing or muting the dialog during the pause cancels playback.
- Reduced connection notices in raffles and number votes. Empty viewer and winner chat windows now show chat when the first message arrives.

App **0.4.13** · Microsoft Store **1.4.13.0**
