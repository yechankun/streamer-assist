# Streamer Assist v0.4.1

## 한국어

- YouTube 웹 다시보기 채팅을 추출하는 비공식 수집 코드와 yt-dlp 다운로드·실행·파서를 제거했습니다. 다시보기 수집은 Twitch·치지직을 지원합니다.
- YouTube는 모든 기록 방식에서 방송 중 공식 API로 받은 채팅 원본을 저장합니다. 방송 종료 후 저장된 기록을 분석하며, 이전 YouTube 다시보기 작업의 자동 재시도를 중단합니다. 앱 실행 전이나 연결 공백 중 채팅을 사후 복원하지는 못합니다.
- YouTube 연결·재개 전에 최종 이용약관, 개인정보처리방침과 30일 보관 정책에 명시적으로 동의합니다. 기존 기록에 적용되는 삭제 범위를 먼저 보여줍니다.
- 연결 일시 중지·재개와 권한 철회·데이터 삭제를 구분합니다. 철회·만료 정리는 암호화한 진행 상태로 재시도하고 다른 플랫폼 원본과 수동 마커를 보존합니다.
- YouTube 데이터의 외부 AI 분석 실행 전에 제공자·모델·기록 범위·식별 정보 포함 여부와 원문 전송을 확인합니다. 취소하면 전송하지 않습니다.
- 한·영 약관·개인정보처리방침과 OAuth 제출 안내를 갱신했습니다.

앱 버전은 **0.4.1**, Store MSIX 버전은 **1.4.1.0**입니다. 종료된 방송의 전체 채팅을 조회하는 YouTube 공식 API는 제공되지 않습니다. Google OAuth 검증과 YouTube 분석 기능의 정책 적용 확인은 별도 절차이며 이 릴리스가 승인을 의미하지 않습니다.

## English

- Remove unofficial YouTube web replay-chat collection, including the yt-dlp downloader, execution path and parser. Replay collection supports Twitch and CHZZK.
- Retain YouTube chat received through the official live API in every recording mode, then analyze those stored originals after the broadcast. Stop automatic retries of legacy YouTube replay jobs. Messages from before connection or during connection gaps cannot be recovered afterward.
- Require explicit acceptance of the final terms, privacy policy and 30-day retention policy before connecting or resuming YouTube. Show the affected existing records before applying cleanup.
- Separate pause/resume from revocation and data deletion. Retry interrupted revocation/retention cleanup using encrypted progress records, while preserving other platforms' originals and manual bookmarks.
- Confirm the provider, model, record scope, identity setting and original-text transfer before external AI analysis of YouTube data. Canceling sends no request.
- Update bilingual terms, privacy policies and OAuth submission instructions.

App version: **0.4.1**. Store MSIX version: **1.4.1.0**. The official YouTube API does not provide full chat for ended broadcasts. Google OAuth verification and confirmation of analysis-specific YouTube policy requirements are separate processes; this release does not imply approval.
