# Streamer Assist v0.4.6

## 한국어

- Windows의 **동작 줄이기**가 켜져 있을 때 방송용 추첨·룰렛 연출까지 생략되던 문제를 수정했습니다. 시청자 슬롯머신은 3초, 일반·숫자 투표·도네 투표 결과 룰렛은 4~7초 동안 재생합니다.
- **설정 → 일반 → 추첨·룰렛 연출**에서 별도로 켜고 끌 수 있습니다. 기본으로 켜져 있으며 선택은 모든 창과 재시작 후에도 유지합니다. 끄면 결과를 즉시 표시합니다. 진행 중인 추첨 시각과 당첨 확률·가중치 계산은 유지합니다.
- 선택형 당첨자 픽셀 캐릭터에 발을 고정한 **3.6초 주기의 작은 숨쉬기 모션**을 추가했습니다. 모든 부품이 함께 움직여 앞뒤 관계를 유지하고, 화면 숨김·비활성 상태에서는 정지합니다. 캐릭터 대기 모션과 장식 효과는 시스템의 동작 줄이기를 따릅니다.
- 900 × 650 창과 글자 크기 150%에서도 새 설정 스위치가 잘리지 않도록 배치했습니다.

앱 버전: **0.4.6** · Microsoft Store MSIX 버전: **1.4.6.0**.

## English

- Fix Windows **reduced motion** silently skipping broadcast draw animations. Viewer slot reels play for 3 seconds; ordinary roulette and roulette imported from numeric/donation polls spin for 4–7 seconds.
- Add **General → 추첨·룰렛 연출**, a saved broadcast-animation switch that defaults on independently of Windows UI motion. Turning it off reveals the result immediately. The choice synchronizes across windows and restarts; an in-progress draw's timing and selection odds remain unchanged.
- Add a subtle **3.6-second breathing cycle** to optional pixel winner characters. One foot-anchored rig moves all parts together, preserving depth and joins. Idle motion pauses while hidden/inactive and, like decorative effects, respects system reduced motion.
- Keep the new switch accessible in a 900 × 650 window with 150% text.

App version: **0.4.6** · Microsoft Store MSIX version: **1.4.6.0**.

*The preview captures the production renderer and motion with synthetic data.*
