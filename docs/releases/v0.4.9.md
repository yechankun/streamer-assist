# Streamer Assist v0.4.9

## 한국어

- Windows의 **동작 줄이기**가 켜져 있으면 앱에서 연출을 켜도 당첨 폭죽·색종이가 표시되지 않던 문제를 수정했습니다.
- 슬롯머신·룰렛 회전·당첨 축하 효과는 **설정 → 일반 → 추첨·룰렛 연출**을 따릅니다. 연출을 끄면 축하 효과를 즉시 중지하고, 다시 켜거나 같은 결과 화면으로 돌아와도 이전 당첨 효과를 반복하지 않습니다.
- 룰렛 채우기 미리보기, 캐릭터 숨쉬기·채팅 반응, 득표수·그래프 변화, 화면 전환, AI 로딩 표시와 TTS 파형도 Windows 모션 설정과 무관하게 재생합니다.
- 숨김·비활성 상태에서는 불필요한 재생을 정지합니다. 비활성 탭의 득표수는 중간 애니메이션 없이 최신 값으로 갱신합니다.
- Windows 동작 줄이기 켜짐·꺼짐, 앱 연출 켜기·끄기, 일반·숫자 투표·도네 투표 룰렛, 두 테마와 150% 글자 크기에서 실제 렌더링과 기존 동작을 검증했습니다.

앱 버전: **0.4.9** · Microsoft Store MSIX 버전: **1.4.9.0**.

## English

- Fix winner fireworks and confetti being suppressed by Windows reduced motion even when the app's draw animations are enabled.
- Slot reels, roulette spins and winner celebrations follow **설정 → 일반 → 추첨·룰렛 연출**. Disabling it immediately stops celebration effects. Re-enabling it or returning to the same result does not replay an old celebration.
- Keep roulette preview filling, character breathing/chat reactions, vote counter/bar interpolation, screen transitions, AI loading indicators and TTS waveforms independent of Windows motion settings.
- Preserve hidden/inactive playback cleanup. Inactive vote counters update directly to the latest value without animating intermediate frames.
- Verify both Windows motion preferences, the saved app animation control, ordinary/poll-result/donation-result roulette, both themes and 150% text through actual renderer tests.

App version: **0.4.9** · Microsoft Store MSIX version: **1.4.9.0**.
