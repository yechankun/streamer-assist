# Streamer Assist v0.4.0

## 한국어

- 실시간 저장·방송 종료 후 분석·다시보기 채팅 수집 중 방송 기록 방식을 선택합니다. 제공되는 VOD 채팅을 기존 기록과 합치며 영상·음성은 내려받지 않습니다.
- 도구 탭 복제·분리 창·창 간 이동과 재시작 후 배치 복원을 지원합니다. 상단 바를 자동으로 숨길 수 있습니다.
- 숫자·도네 투표에 분·초 단위 종료 타이머를 추가하고 시청자 추첨 화면을 개선했습니다.
- 타임라인 탭 위치, 키보드 포커스와 창 확대 시 동접 그래프의 축 숫자·시간 표시를 수정했습니다.
- 채팅 수집·중복 확인·참여자 통계·기록 조회의 처리 비용을 줄였습니다.
- 한·영 사용 가이드와 실제 앱 스크린샷을 갱신했습니다.

앱 버전은 **0.4.0**, Store MSIX 버전은 **1.4.0.0**입니다. 화면 언어는 한국어입니다. 실제 연결에는 플랫폼 권한이 필요하며 삭제되거나 제공되지 않는 다시보기 채팅은 복구할 수 없습니다.

## English

- Choose live storage, analysis after the broadcast, or replay-chat collection. Merge available VOD chat with existing records without downloading video or audio.
- Duplicate tool tabs, move them between separate windows, and restore layouts after restart. The topbar can hide automatically.
- Set number/donation vote timers in minutes and seconds; use the improved viewer raffle screen.
- Timeline tabs keep a stable position. Keyboard focus and viewer-axis values/timestamps remain readable when resizing.
- Reduce chat ingestion, deduplication, participant statistics and archive-query processing costs.
- Refresh bilingual guides and actual app screenshots.

App version: **0.4.0**. Store MSIX version: **1.4.0.0**. The interface is Korean. Real connections require platform permissions; deleted or unavailable replay chat cannot be recovered.
