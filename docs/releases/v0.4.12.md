# Streamer Assist v0.4.12

## 한국어

- 명단 위 스피커를 켜 두면 당첨자 창이 열릴 때 추첨 직전의 마지막 채팅을 한 번 읽고, 이후 도착한 채팅을 순서대로 읽습니다.
- 모집이 끝나면 **모집 재개**로 명단과 당첨 기록을 이어 가거나 **추첨 초기화**로 둘 다 비우고 준비 화면으로 돌아갈 수 있습니다.
- 탭 바를 자동으로 숨긴 상태에서도 화면 상단의 빈 공간을 끌어 창을 옮길 수 있습니다.
- Microsoft Store의 한국어·영어 소개에 이번 버전의 실제 화면 10장을 담았습니다.

앱 **0.4.12** · Microsoft Store **1.4.12.0**

## English

- Enable the roster speaker to hear the winner’s last message before the draw once, followed by incoming chat in order.
- After recruitment ends, **모집 재개** resumes with the same roster and draw history. **추첨 초기화** clears both and returns to setup.
- When the tab bar is hidden, drag the empty area at the top of the window to move it.
- The Korean and English Microsoft Store galleries feature ten screenshots captured in this release.

App **0.4.12** · Microsoft Store **1.4.12.0**
