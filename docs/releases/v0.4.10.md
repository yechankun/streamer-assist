# Streamer Assist v0.4.10

## 한국어

- 시청자 추첨 진행 화면에서 참여 방식·구독자 조건·이전 당첨자 제외를 버튼으로 바로 바꿉니다. 키워드 방식을 누르면 현재 참여 키워드를 표시하고 바로 편집하며, Enter 또는 다른 곳 클릭으로 적용합니다. 빠른 연속 토글과 키워드 저장 직후의 클릭도 함께 반영합니다.
- 참여자 수 옆의 플랫폼 아이콘으로 추첨 대상을 실시간으로 켜고 끕니다. 모두 꺼도 경고 없이 명단과 당첨 기록을 보존하며, 제외된 대상은 흐리게 표시합니다.
- 추첨하기를 누르면 모집을 자동 종료하고 그 시점의 명단으로 추첨합니다. 다시 모집은 기존 명단과 당첨 기록을 유지하며, 새 추첨 준비에서 새 모집을 시작하면 초기화합니다.
- 경과 시간에 마우스를 올리면 타이머 편집기가 옆으로 펼쳐집니다. 슬라이더·숫자를 바꾼 뒤 확인을 눌러야 즉시 카운트다운이 시작됩니다. 보기만 하고 벗어나면 접히며, 클릭 후에도 열린 채 남지 않습니다. 모집 종료 상태에서 타이머를 적용하면 같은 명단으로 모집을 재개합니다.
- 명단 위 얼굴 아이콘 옆에 시청자·당첨자 새 채팅 자동 읽기 스피커를 추가했습니다. 채팅창 스피커와 같은 설정을 공유하며 앱을 다시 실행해도 유지합니다. 이전 메시지는 다시 읽지 않고, 음성 선택·온라인 음성 동의·창 숨김/닫기 시 재생 정리를 유지합니다.
- 제목 직접 수정, 키보드·한국어 입력, 두 테마, 작은 창과 150% 글자 크기, 기존 당첨·룰렛 연출을 검증했습니다.

앱 버전: **0.4.10** · Microsoft Store MSIX 버전: **1.4.10.0**.

## English

- Replace the live raffle settings modal with inline entry-mode, subscriber and previous-winner toggles. Keyword mode displays and focuses the current keyword for editing; Enter or blur applies it. Preserve rapid toggles and clicks immediately following keyword edits.
- Toggle eligible platforms beside the participant count, including turning every platform off without warnings. Preserve the roster and winner history, and dim ineligible entrants.
- Automatically close recruitment when drawing and freeze the eligible roster. Resume recruitment with existing entrants and history, or prepare a fresh round to reset them.
- Expand the timer editor sideways on clock hover. Slider and numeric edits apply only after confirmation, starting a countdown immediately. Untouched mouse previews collapse on exit, including after clicking the clock. Applying a timer to a closed roster resumes recruitment with the same entrants.
- Add a saved viewer/winner chat auto-read speaker beside the roster's character icon. Chat-window speakers share the setting across windows and restarts. Never replay old messages; retain voice selection, online-voice consent and playback cleanup when hiding or closing a chat.
- Verify inline title edits, keyboard and Korean text entry, both themes, small windows, 150% text and existing winner/roulette effects.
