[English](performance.md) · [개발 가이드](development.ko.md)

**2026-10-06**에 Windows x64, Node.js 22, Electron 41.10.7로 측정한 로컬 예시입니다. 모든 PC의 보장 값이나 GitHub 실행기의 실측은 아닙니다.

| --- | ---: | ---: | --- |
| 새 화면 빌드 | 5.350초 | 3.343초 | 같은 npm 명령·새 타입 검사 상태. |
| 변경 없는 화면 빌드 | 5.350초 | 0.436초 | npm 시작·소스/결과 해시 검증 포함. |

| 측정 당시 데스크톱 8종 | 62.450초 | 41.657초 | 화면 빌드 제외·검증 유지. |

위 값은 당시 코드·검사 범위의 기록입니다. 현재 `npm run test:desktop`은 AI·탭/창 배치·공용 수집·글자 크기를 포함한 14종이며 단위 검사도 추가되었습니다. 위 실행 시간·126개 검사 수·패키지 크기를 현재 빌드의 측정값으로 사용하지 않습니다. 현재 시간은 아래 명령으로 새 보고서를 생성해 확인합니다.

최종 EXE는 **89,391,057바이트**, MSIX는 **135,846,017바이트**였습니다. 원래 압축 설정·패키지 내용을 유지한 병렬 처리이며 검증을 생략하거나 무압축으로 만든 결과가 아닙니다.

## 합성 기록 측정

24일·채팅 24,000건의 암호화 파일은 **741,456 → 566,024바이트(23.7% 감소)**였습니다. 첫 날짜 조회는 **91개 → 1개** 청크를 읽었고 5회 중앙값은 **80.81 → 0.90ms**였습니다.

저속 기록 예시에서 1초 저장 120회를 수행한 결과 **120개 파일·46,268바이트 → 1개·2,032바이트**였습니다. 1초 저장 주기를 유지하고 같은 날짜의 제한된 마지막 파일을 원자적으로 합칩니다.

AES-GCM 테스트 저장소를 사용하므로 Windows DPAPI 실제 시간과는 다릅니다. 디스크·운영체제 캐시·채팅 패턴·기록 크기에 따라 결과가 달라집니다. 개인 프로필이나 실제 채팅을 측정하지 않았습니다.

## 재현

- `npm run benchmark:timeline`은 임시 합성 데이터를 만들고 정리합니다. 새 체크아웃은 현재 결과를 출력하며 이전 비교에는 로컬로 보관한 이전 코드가 필요합니다.
- `npm run build`는 `release/renderer-build-timings.json`을 기록합니다. 새 번들은 `node scripts/build.cjs --force`, 증분 타입 상태 초기화는 `.build-cache/typescript.tsbuildinfo`만 제거합니다.
- `npm run test:desktop`은 `release/desktop-test-results.json`에 검사별 시간을 남깁니다. 선택 실행은 별도 보고서를 사용합니다.
- `npm run dist:all`은 `release/build-timings.json`을 기록합니다. 겹쳐 실행되는 단계 시간을 더한 값은 전체 시간과 다릅니다.
- 로컬 비교 보고서는 `release/build-performance-report.json`·`release/test-performance-report.json`입니다. 생성 결과는 Git에서 제외합니다.

캐시 검사는 수정 시각을 유지한 편집, 결과 변조·누락, 환경·가져온 파일 변화와 네이티브 의존성 추가를 확인합니다. 실제 TypeScript 오류를 넣어 게시 실패·이전 결과 보존·오래된 소스의 패키징 차단도 확인했습니다.
