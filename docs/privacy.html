Streamer Assist 개인정보처리방침

적용일: 2026-10-06
운영자: yechankun · Streamer Assist 개발자

1. 처리하는 정보와 목적

방송 기록에는 제목·마커·시작/종료 시각·연결 방송 정보, 채팅 원문과 메시지 발생·수신 시각, 후원 금액·통화·메시지, 시점별 동시 시청자 수를 저장합니다. 반응·키워드·질문·반복 문구와 참여자별 통계는 이 PC에서 계산합니다.

시청자 추첨과 중복 투표 방지를 위해 플랫폼 계정 식별자, 닉네임, 구독·멤버십 여부, 참여·당첨 기록과 후원 이벤트 식별자를 처리합니다. 후원 투표는 플랫폼이 전달한 후원 금액·통화·메시지를 표수 계산에 사용합니다. 결제 수단이나 은행 계좌 정보를 입력받지 않습니다. 채팅 분석을 위해 플랫폼이 제공한 공개 계정 식별자·닉네임 변화·구독 여부·역할·배지를 기록합니다. 플랫폼이 다른 계정을 닉네임만으로 합치지 않습니다.

YouTube·트위치 연결 시 채널 정보와 접근·갱신 토큰을, 치지직 연결 시 공개 채널 주소·이름을 저장합니다. 트위치 로그인 중에는 일회용 기기 인증 정보와 승인 코드를 메모리에서 처리하며 로그인 완료·취소 후 폐기합니다. 앱 설정과 룰렛 제목·항목·가중치도 이 PC에 저장합니다.

2. 외부 연결

사용자가 연결한 치지직·YouTube·트위치 API에 채팅·방송 조회 및 투표 요청을 보냅니다. 저장된 연결은 앱 재실행 시 다시 연결할 수 있습니다. YouTube 로그인은 기본 브라우저에서 Google의 동의를 받아 진행하며 127.0.0.1의 임시 콜백으로 결과를 받습니다. 트위치 로그인은 기본 브라우저에서 Twitch의 채팅 읽기 동의를 받고 앱에서 Device Code 방식으로 인증 결과를 확인합니다. 트위치 채팅은 공식 EventSub WebSocket으로 수신합니다.

이 앱은 개발자 서버로 방송 기록·채팅·로그인 토큰을 업로드하지 않습니다. 광고·분석·원격 오류 수집 SDK를 사용하지 않습니다. 플랫폼과 브라우저, Microsoft Store 및 문의 게시판은 각 서비스의 개인정보처리방침이 적용됩니다.

3. 저장과 보안

방송·참여·투표 기록과 YouTube·트위치 계정 토큰은 Windows 보안 저장소(DPAPI)를 이용하여 암호화한 파일로 앱 프로필에 저장합니다. 기존 평문 방송 기록은 암호화 저장이 성공한 뒤 마이그레이션합니다.

단축키·트레이·채널 연결 설정과 테마·룰렛 입력값은 이 PC의 앱 설정 파일 또는 브라우저 로컬 저장소에 보관합니다. 사용자가 직접 선택한 Markdown·JSON·JSONL 내보내기는 암호화되지 않은 일반 파일입니다. 공유 여부는 사용자가 결정합니다.

4. 보관 기간

방송·채팅·후원·시청자 기록은 사용자가 삭제할 때까지 이 PC에 보관합니다. 원본은 방송별·날짜별 암호화 파일로 저장하며 방송 타임라인 → 채팅·후원 → 날짜·용량 관리에서 범위를 선택해 삭제하거나 설정 → 정보·데이터에서 전체 기록을 삭제할 수 있습니다.

현재 추첨은 최대 10,000명, 현재 후원 투표는 최대 50,000개 이벤트를 처리합니다. 참여·당첨·후원 중복 방지 기록은 새 모집·투표로 교체하거나 데이터 삭제를 실행할 때까지 보관합니다. 암호화 복구 백업이 생기면 기록 삭제 시 함께 제거합니다.

5. 사용자 제어와 삭제

방송 타임라인의 날짜·용량 관리에서 선택한 날짜의 모든 플랫폼 채팅·후원·시청자 기록을 확인 후 삭제할 수 있습니다. 진행 중인 방송에 속한 날짜는 보호하며 다른 날짜와 마커는 유지합니다. 설정 → 정보·데이터의 전체 삭제는 진행 중인 방송 기록·투표·모집·추첨을 종료한 뒤 실행합니다. 룰렛 목록은 별도로 초기화합니다.

설정 → 플랫폼 연결에서 계정·채널 연결을 해제할 수 있습니다. Google 측 권한 철회는 Google 계정의 연결된 앱 관리에서 진행합니다. 앱의 계정 연결 해제는 이 PC의 저장된 연결을 제거합니다.

사용자가 내보낸 파일과 별도로 복사한 백업은 직접 삭제해야 합니다. Microsoft Store 패키지 제거·재설정에 따른 처리는 Windows의 앱 데이터 관리 방식에 따릅니다. AI 분석용 JSONL은 기본적으로 공개 계정 ID를 제거하고 닉네임을 가명으로 바꾸며 분석용 화자 키는 유지합니다. 사용자가 공개 식별 정보 포함을 선택할 수 있습니다. 채팅 본문과 마커·반응 예시는 원문이므로 그 안에 적힌 개인정보를 자동으로 제거하지 않습니다. 외부 AI 분석은 사용자가 분석 실행을 누를 때만 수행합니다.

6. 선택적 AI 연결과 분석

설정 → AI 연결에서 Codex/OpenAI, Claude, Grok, Antigravity/Gemini, DeepSeek, Kimi 또는 직접 추가한 호환 API를 선택할 수 있습니다. CLI 구성요소는 사용자가 설치를 선택한 경우 공식 배포처에서 이 PC의 앱 전용 폴더로 내려받으며 설치 프로그램에는 포함하지 않습니다. 이미 설치된 CLI도 사용할 수 있습니다.

API 키는 Windows 보안 저장소로 암호화하고 렌더러에 저장된 키를 반환하지 않습니다. CLI 로그인 정보는 각 CLI가 관리합니다. AI 분석 실행을 누르면 선택한 방송·날짜·플랫폼·시간 범위의 기록과 요청을 선택한 외부 AI 서비스로 전송합니다. 자동으로 AI 분석을 실행하거나 개발자 서버를 거쳐 전송하지 않습니다. localhost API를 직접 추가하면 해당 PC의 서버로 요청합니다.

전송 전 포함되는 기록 수·용량·대략적인 토큰 수와 샘플링 여부를 표시합니다. 기본값은 닉네임 가명화와 공개 계정 ID 제거이며 같은 화자를 연결하는 분석 ID와 채팅·후원 본문, 시점은 유지합니다. 본문에 적힌 개인정보는 자동으로 제거되지 않습니다. 사용자는 공개 식별 정보 포함을 선택할 수 있습니다.

AI 결과는 이 PC에 암호화해 저장하며 분석 결과 화면에서 삭제할 수 있습니다. 외부 서비스의 처리·보관·요금은 각 서비스의 정책에 따릅니다. CLI는 자체 로그·세션을 보관할 수 있으며 앱에서 분석 결과를 삭제해도 외부 서비스나 CLI가 보관한 기록까지 삭제하는 것은 아닙니다.

GitHub에서 내려받는 LLM별 연결 모듈은 앱 프로필에 설치하며 API 키·방송 기록·분석 결과와 별도로 보관합니다. 모듈 버전 확인과 다운로드는 지정된 공개 GitHub 저장소에 요청하며 해당 요청에 AI API 키나 채팅 내용을 포함하지 않습니다.

7. 문의와 변경

개인정보 처리 문의는 프로젝트의 GitHub Issues 또는 Store에 등록된 개발자 연락처로 받습니다. 공개 게시판에 계정 토큰이나 타인의 개인정보를 올리지 마세요.

처리하는 정보나 기능이 바뀌면 이 문서의 버전을 갱신합니다. 앱 안의 정보·데이터 화면과 공개 문서에서 최신 방침을 확인할 수 있습니다.
