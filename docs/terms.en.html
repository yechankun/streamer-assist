1. Application and permitted use

These terms describe version 0.4.1 and later. Update the application to use the revised consent and retention controls. Earlier versions may have different behavior; consult the policy bundled with that version.

Streamer Assist is a Windows desktop application for broadcast archives, audience participation, polls, roulette and optional record analysis. Connect only accounts and channels you are authorized to use and follow the applicable platform terms.

This is an independent application, not an official product or affiliate of NAVER, CHZZK, Google, YouTube or Twitch. Features depend on platform authorization, API availability and service status.

2. YouTube features and authorization

Streamer Assist uses YouTube API Services. By using its YouTube features, you agree to be bound by the YouTube Terms of Service. Review and accept these terms and the privacy policy before connecting. Google authorization is granted separately on Google's consent screen.

The connection identifies your authorized channel and active broadcast, receives live chat and supported Super Chat messages, and creates or closes native live polls at your request. Check the broadcast channel, question and options before publishing. The app does not publish polls without your request or edit/delete videos or comments.

The app does not extract replay chat from YouTube web pages or bypass unavailable data. Supported features are described in the application and release documentation.

3. Data and user control

The privacy policy explains collected data, purposes, external connections and security. Pause connection keeps account tokens and records while stopping collection. Revoke access and delete data requests confirmation before revoking Google access and cleaning related app-managed YouTube records.

Original YouTube chat, identifiers and broadcast metadata are subject to a 30-day retention limit. The app checks periodically while running and checks for expiry before records are used after a long period of inactivity. When applying this policy to older-version records for the first time, it shows the deletion scope and impact and requests confirmation. Other platforms' originals and manually written bookmarks are preserved.

Network or storage errors are reported as pending and retried. Checks and deletion do not execute while the app is closed. Deleting local app records does not delete the original data on YouTube. You manage exported files and separately copied backups.

Legacy YouTube web replay data and recovery records without identifiable session metadata are included in the reviewed cleanup scope. YouTube continues to use official live API collection when other platforms use replay mode.

4. Optional AI analysis

AI analysis is optional and sends your selected records and request to your chosen provider and model. Before execution, the app identifies the destination, scope and inclusion of public identity fields and requests consent. Google account tokens and AI API keys are not included in the analysis materials.

AI output can contain errors or omissions and should be reviewed. Check your provider's charges, processing, retention and data-use terms. Deleting app results does not delete provider-held copies or a CLI's own logs and sessions. Permission to use data for model training is distinct from a user's analysis request. The app does not guarantee unverified provider data-use terms.
